บทที่ 7: กฎของเกาส์และผิวสมมาตร (Gauss's Law & Symmetrical Surfaces)

กฎของเกาส์ในรูปอินทิกรัลผิวปิด ∮ D • ds = Qenc, หลักเกณฑ์การเลือกผิวเกาส์เซียนสมมาตร 3 รูปแบบ (ทรงกลม, ทรงกระบอก, แผ่นระนาบ), และเทคนิคการหาความหนาแน่นฟลักซ์ D และสนามไฟฟ้า E โดยไม่ต้องอินทิเกรตคูลอมบ์ที่ซับซ้อน

วัตถุประสงค์การเรียนรู้ประจำบท (Learning Objectives):

  1. เข้าใจข้อความทางฟิสิกส์และสมการอินทิกรัลผิวปิดของ กฎของเกาส์ (Gauss's Law): ∮S D • ds = Qenc
  2. เข้าใจนิยามและทิศทางของ เวกเตอร์พื้นที่ผิวส่วนย่อย (Differential Surface Vector, ds = dS an) ซึ่งต้องมีทิศพุ่งออกจากผิวปิดในแนวตั้งฉากเสมอ
  3. จดจำและประยุกต์ เงื่อนไขสำคัญ 2 ประการ ในการเลือกผิวเกาส์เซียนสมมติ (Symmetrical Gaussian Surface) เพื่อดึง |D| ออกนอกเครื่องหมายอินทิกรัล
  4. แสดงการพิสูจน์หา D และ E ใน 3 โครงสร้างสมมาตรคลาสสิก: ลูกบอลประจุทรงกลมตัน (r ≤ a และ r > a), สายส่งโคแอกเชียล (Coaxial Cable), และแผ่นระนาบประจุคู่ขนาน

1. นิยามและสมการของกฎของเกาส์ (Gauss's Law Formulation)

จากการทดลองของฟาราเดย์ในบทที่ 6 ทำให้ทราบว่า ฟลักซ์ไฟฟ้า Ψ ที่แผ่ออกจากประจุใดๆ มีค่าเท่ากับประจุที่ล้อมรอบเสมอ คาร์ล ฟรีดริช เกาส์ (Carl Friedrich Gauss) ได้ขยายแนวคิดนี้ให้กลายเป็นกฎทางฟิสิกส์พื้นฐานที่ทรงพลังยิ่ง:

ข้อความของกฎของเกาส์ (Statement of Gauss's Law):

"ฟลักซ์ไฟฟ้าทั้งหมดที่พุ่งผ่านผิวปิดสมมติ (Closed Surface) ใดๆ ย่อมมีค่าเท่ากับประจุไฟฟ้าสุทธิทั้งหมดที่ถูกล้อมรอบอยู่ภายในผิวปิดนั้นพอดี"
(The electric flux passing through any closed surface is equal to the total charge enclosed by that surface.)

เนื่องจากฟลักซ์ไฟฟ้าส่วนย่อย dΨ ที่พุ่งตัดผ่านพื้นที่ผิวส่วนย่อย ds สัมพันธ์กับความหนาแน่นฟลักซ์ D ด้วยผลคูณจุด: dΨ = D • ds เมื่อรวมฟลักซ์รอบผิวปิดทั้งหมด S จึงได้สมการกฎของเกาส์ในรูปอินทิกรัล:

สมการกฎของเกาส์ในรูปอินทิกรัล (Integral Form of Gauss's Law)
Ψ = ∮S D • ds = Qenc
เมื่อ:
• ∮S = การอินทิเกรตบนผิวปิด (Closed Surface Integral) ที่หุ้มล้อมรอบปริมาตร v ไว้อย่างสมบูรณ์
• D = เวกเตอร์ความหนาแน่นฟลักซ์ไฟฟ้าบนผิว S (หน่วย: C/m²)
• ds = dS an = เวกเตอร์พื้นที่ผิวส่วนย่อยที่มีทิศพุ่งออกตั้งฉากกับผิวปิด (หน่วย: m²)
• Qenc = ปริมาณประจุไฟฟ้าสุทธิทั้งหมดที่ถูกล้อมรอบอยู่ภายในผิวปิด S (หน่วย: C)

หากประจุไฟฟ้าภายในผิวปิด S มีการกระจายตัวแบบต่อเนื่องในปริมาตร v ด้วยความหนาแน่น ρv ประจุล้อมรอบ Qenc จะมีค่าเท่ากับ:

∮S D • ds = ∫vol ρv dv = Qenc

2. เวกเตอร์พื้นที่ผิวส่วนย่อยชี้ออกในแนวตั้งฉาก (Differential Surface Vector, ds)

ในการอินทิเกรตตามกฎของเกาส์ ทิศทางของเวกเตอร์พื้นที่ผิว ds มีกฎเกณฑ์ตายตัวตามมาตรฐานสากล:

ds = dS an
โดยที่ an คือ เวกเตอร์หนึ่งหน่วยที่ตั้งฉากกับพื้นผิวและชี้พุ่งออกจากปริมาตรปิดเสมอ (Outward Normal Unit Vector)
ระบบพิกัด ผิวคงที่ (Constant Surface) เวกเตอร์พื้นที่ผิวชี้ออก (Outward ds) การประยุกต์ในกฎของเกาส์
พิกัดทรงกลม (Spherical) ผิวทรงกลม r = const ds = r² sin θ dθ dϕ ar ผิวเกาส์เซียนรอบจุดประจุและทรงกลม
พิกัดทรงกระบอก (Cylindrical) ผิวด้านข้าง ρ = const ds = ρ dϕ dz aρ ผิวด้านข้างของลวดประจุและสายโคแอกเชียล
พิกัดทรงกระบอก (ฝาบน/ฝาล่าง) ฝาบน z = +L/2, ฝาล่าง z = -L/2 dstop = ρ dρ dϕ az
dsbot = -ρ dρ dϕ az		 ฝาปิดทรงกระบอก (สนาม D ขนานผิว ⇒ ฟลักซ์เป็นศูนย์)
พิกัดฉาก (Cartesian Pillbox) ฝาบน z = +h, ฝาล่าง z = -h dstop = dx dy az
dsbot = -dx dy az		 กล่องเกาส์เซียนประกบแผ่นประจุระนาบ

3. หลักการและเงื่อนไขสำคัญในการเลือกผิวเกาส์เซียน (Gaussian Surface Selection)

แม้ว่ากฎของเกาส์จะเป็นจริงสำหรับผิวปิดรูปทรงใดๆ ก็ตามในเอกภพ แต่การจะใช้กฎของเกาส์เพื่อคำนวณหาขนาดของสนาม D ได้อย่างง่ายดายโดยไม่ต้องทำการอินทิเกรตที่ซับซ้อน เราจะต้องเลือกผิวปิดสมมติ (เรียกว่า ผิวเกาส์เซียน / Gaussian Surface) ให้สอดคล้องกับ เงื่อนไขความสมมาตร 2 ประการ ดังต่อไปนี้:

เงื่อนไขที่ 1

ขนาดของสนาม |D| มีค่าสม่ำเสมอคงที่ทั่วทั้งพื้นผิว

ผิวเกาส์เซียนต้องวางตัวในระยะที่สมมาตรกับประจุต้นเหตุ เพื่อให้ขนาดสเกลาร์ D = |D| มีค่าคงที่ ณ ทุกๆ จุดบนผิวนั้น ส่งผลให้เราสามารถ ดึงค่าคงที่ D ออกมานอกเครื่องหมายอินทิกรัลได้:

∮S D • ds = Dn ∮S dS = Dn · Sarea
เงื่อนไขที่ 2

เวกเตอร์ D ต้องตั้งฉากกับผิว (ขนานกับ ds) หรือขนานกับผิว (ตั้งฉากกับ ds) เสมอ

ในทุกๆ ชิ้นส่วนของผิวปิด S:

  • เมื่อ D ตั้งฉากกับผิว (D ขนานกับ ds): จะได้ D • ds = |D| |ds| cos(0°) = D dS (เกิดฟลักซ์เต็มที่)
  • เมื่อ D ขนานกับผิว (D ตั้งฉากกับ ds): จะได้ D • ds = |D| |ds| cos(90°) = 0 (ไม่มีฟลักซ์พุ่งทะลุผิวนั้นเลย ฟลักซ์เป็นศูนย์อย่างแท้จริง)

ทดลองเลือกชนิดโครงสร้างสมมาตรของประจุ ปรับค่าประจุหรือความหนาแน่นประจุ และปรับระยะรัศมี r เพื่อดูการคำนวณอินทิกรัล ∮ D • ds = Qenc และการสร้างผิวเกาส์เซียนสมมติแบบ 3 มิติ

4. การประยุกต์ที่ 1: สมมาตรทรงกลม (Spherical Symmetry)

4.1 จุดประจุ Q ที่จุดกำเนิด (Point Charge)

เลือกผิวเกาส์เซียนเป็น ผิวทรงกลมสมมติรัศมี r ที่มีจุดศูนย์กลางร่วมกับจุดประจุ:

∮S D • ds = ∫ϕ=02π ∫θ=0π Dr (r² sin θ dθ dϕ) = Dr (4π r²)
Dr (4π r²) = Qenc = Q    ⇒    D = Q4π r² ar     และ     E = Q4πε₀ r² ar

4.2 ทรงกลมตันประจุกระจายสม่ำเสมอ (Uniform Volume Charge Ball)

กำหนดทรงกลมตันรัศมี a มีความหนาแน่นประจุเชิงปริมาตรคงที่ ρv C/m³ (ประจุรวม Qtotal = ρv (4/3 π a³)):

กรณีที่ 1: ภายในทรงกลม (r ≤ a)

ประจุที่ถูกผิวเกาส์เซียนรัศมี r ล้อมรอบอยู่:

Qenc = ∫0r ρv (4π r'² dr') = ρv (43 π r³)

แทนลงในกฎของเกาส์:

Dr (4π r²) = ρv (43 π r³)    ⇒    D = ρv r3 ar     (สนามแปรผันตรงกับระยะ r)
กรณีที่ 2: ภายนอกทรงกลม (r > a)

ผิวเกาส์เซียนล้อมรอบประจุของลูกบอลทั้งลูก:

Qenc = ρv (43 π a³) = Qtotal
Dr (4π r²) = ρv (43 π a³)    ⇒    D = ρv a³3 r² ar = Qtotal4π r² ar

5. การประยุกต์ที่ 2: สมมาตรทรงกระบอก (Cylindrical Symmetry)

สำหรับเส้นประจุอนันต์ ρl C/m บนแกน z เลือกผิวเกาส์เซียนเป็น ทรงกระบอกตันสมมติรัศมี ρ ความยาว L ปิดหัวท้าย:

∮S D • ds = ∫top D • ds + ∫bottom D • ds + ∫side D • ds
• ฝาบนและฝาล่าง: D มีทิศในแนว aρ แต่ ds มีทิศในแนว ±az ดังนั้น D • ds = 0 (ฟลักซ์เป็นศูนย์)
• ผิวด้านข้าง: D ขนานกับ ds และมีขนาดคงที่ Dρ
∮S D • ds = Dρ (2π ρ L) = Qenc = ρl L
D = ρl2π ρ aρ      และ      E = ρl2πε₀ ρ aρ

หมายเหตุ: ได้ผลลัพธ์ตรงกับวิธีอินทิเกรตคูลอมบ์ในบทที่ 5 ทุกประการ แต่แก้ปัญหาได้ใน 3 บรรทัดด้วยกฎของเกาส์!

6. การประยุกต์ที่ 3: สมมาตรแผ่นระนาบ (Planar Symmetry)

สำหรับแผ่นระนาบประจุอนันต์ความหนาแน่น ρs C/m² บนระนาบ z = 0 เลือกผิวเกาส์เซียนเป็น กล่องสี่เหลี่ยม (Gaussian Pillbox) พื้นที่หน้าตัดฝาบน-ล่าง ΔS ประกบคร่อมแผ่นระนาบ:

∮S D • ds = ∫top D • ds + ∫bottom D • ds + ∫sides D • ds
• ผนังด้านข้าง 4 ด้าน: D ขนานกับผิวกล่อง (ตั้งฉากกับ ds) ดังนั้น D • ds = 0
• ฝาบน (z > 0): D • ds = Dz ΔS (ทิศ +az)
• ฝาล่าง (z < 0): D • ds = (-Dz) (-ΔS az) = Dz ΔS (ทิศ -az)
∮S D • ds = 2 Dz ΔS = Qenc = ρs ΔS
D = ρs2 an      และ      E = ρs2ε₀ an

7. ตัวอย่างโจทย์สายส่งโคแอกเชียล (Coaxial Cable Analysis)

ตัวอย่างการวิเคราะห์สาย Coaxial

โจทย์: สายส่งโคแอกเชียลยาวอนันต์ประกอบด้วยตัวนำทรงกระบอกด้านในรัศมี a = 1 mm มีความหนาแน่นประจุเชิงผิว ρsa = +8 nC/m² และปลอกตัวนำทรงกระบอกด้านนอกรัศมี b = 4 mm มีความหนาแน่นประจุเชิงผิว ρsb = -2 nC/m² จงหาสนามความหนาแน่นฟลักซ์ D ในทุกๆ บริเวณ

วิธีทำอย่างเป็นระบบ:

  1. หาประจุเชิงเส้นเทียบเท่าบนตัวนำใน (ρl):
    ρl = ρsa (2π a) = (8 × 10⁻⁹) (2π × 10⁻³) = 1.6π × 10⁻¹¹ C/m ≈ 5.027 × 10⁻¹¹ C/m
  2. บริเวณ 1: ภายในตัวนำแกนใน (ρ < a):
    ไม่มีประจุสุทธิภายในเนื้อตัวนำ Qenc = 0 ดังนั้น D = 0
  3. บริเวณ 2: ระหว่างตัวนำทั้งสอง (a < ρ < b):

    เลือกผิวเกาส์เซียนทรงกระบอกรัศมี ρ ความยาว L ล้อมรอบตัวนำใน:

    Dρ (2π ρ L) = Qenc = ρsa (2π a L)
    D = a ρsaρ aρ = (10⁻³) (8)ρ aρ = 8 × 10⁻³ρ aρ nC/m²
  4. บริเวณ 3: ภายนอกปลอกตัวนำนอก (ρ > b):

    ประจุรวมภายในผิวเกาส์เซียนต่อหนึ่งหน่วยความยาว:

    Qenc/L = ρsa (2π a) + ρsb (2π b) = 2π [ (8)(10⁻³) + (-2)(4 × 10⁻³) ] = 2π [ 8 × 10⁻³ - 8 × 10⁻³ ] = 0
    ดังนั้น D = 0 สำหรับบริเวณ ρ > b

8. ตัวอย่างโจทย์ฝึกทักษะระดับ Textbook (Hayt & Buck Drill Problems)

Drill Problem 3.3

กำหนดให้ประจุไฟฟ้าเชิงปริมาตรกระจายตัวในอวกาศด้วยความหนาแน่น ρv = 5 / r C/m³ ในย่าน 0 < r < 2 m และ ρv = 0 ในย่านอื่นๆ จงหาความหนาแน่นฟลักซ์ไฟฟ้า D ณ (ก) r = 1 m และ (ข) r = 3 m

วิธีทำ:

  1. (ก) ที่ r = 1 m (อยู่ภายในย่านประจุ r < 2 m):
    Qenc = ∫02π ∫0π ∫01 (5r') (r'² sin θ dr' dθ dϕ) = 4π ∫01 5r' dr' = 4π [ 5(1)²2 ] = 10π C
    Dr (4π (1)²) = 10π    ⇒    Dr = 10π4π = 2.5 ar C/m²
  2. (ข) ที่ r = 3 m (อยู่ภายนอกย่านประจุ r > 2 m):
    Qenc = 4π ∫02 5r' dr' = 4π [ 5(2)²2 ] = 4π (10) = 40π C
    Dr (4π (3)²) = 40π    ⇒    Dr = 40π36π = 109 ≈ 1.111 ar C/m²

ตอบ: (ก) D(1 m) = 2.5 ar C/m²    (ข) D(3 m) = 1.111 ar C/m²
