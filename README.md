# แพลตฟอร์มการเรียนรู้ 303214 สนามแม่เหล็กไฟฟ้า 1

เว็บภาษาไทยแบบ static สำหรับ Sets 01–22 ใช้ Semantic HTML แสดงสมการ เปิดจากไฟล์โดยตรงหรือผ่านเว็บเซิร์ฟเวอร์ได้ มีแผนผังความรู้ สื่อทดลอง และห้องสอบแยกกลางภาค/ปลายภาค

## เริ่มเรียน

เปิด [พอร์ทัล](index.html) แล้วเลือกช่วงเรียน ทุกหน้ามีปุ่มแผนผังบนแถบนำทางและปุ่มลอยตัว หน้าบทเรียนมีปุ่มในสารบัญด้วย แผนผังแสดงความรู้ก่อนหน้า บทที่เลือก และการนำไปใช้ การทำเครื่องหมายเข้าใจแล้วเป็นการยืนยันของผู้เรียน บันทึกเฉพาะเบราว์เซอร์ที่ใช้

แต่ละบทเริ่มด้วยคำถามฟิสิกส์ ภาพในใจ การพิสูจน์พร้อมเหตุผล และการทดลองที่ปรับค่าได้ จดสิ่งที่ทำนายก่อนปรับค่า แล้วเทียบกับผลและสมมติฐานของแบบจำลอง

## ฝึกสอบและตรวจที่มา

- [ห้องสอบกลางภาค](exam-simulator/midterm/index.html): 11 โจทย์ รวมข้อสอบเก่า 4 ข้อและแบบฝึกหัด Hayt บท 1–4 ชุดต้นฉบับรักษาน้ำหนัก 25/20/30/25
- [ห้องสอบปลายภาค](exam-simulator/final/index.html): 23 รายการ รวมป้าย ALL-Q01–ALL-Q12 แบบฝึกหัดในขอบเขต และอ่านต่อยอด 2 รายการที่ไม่สุ่มเข้าชุดสอบ
- [ใบสูตรกลางภาค](formula-sheet/index.html) และ [ใบสูตรปลายภาค](formula-sheet-final/index.html) เปิดดูระหว่างฝึกได้ ใบสูตรปลายภาคมี 9 หน้าตามไฟล์จริง
- [ดัชนีที่มาซึ่งสอบทานแล้ว](raw/exam-source-analysis.md) ระบุหน้าสไลด์ ตำรา และข้อแตกต่างของต้นฉบับ

ระบบมีชุดเรียงตามต้นฉบับ ชุดสุ่ม 4 หมวด และคลังทั้งหมด พร้อมตัวจับเวลา การเปิดเฉลย บันทึกงาน และส่งออก JSON ข้อมูลแต่ละห้องแยกจากกัน Checklist เป็นการประเมินด้วยตนเองตามสูตรทั่วไป ขั้นวิเคราะห์ด้วยมือ และหน่วย SI ไม่ใช่ระบบตรวจลายมืออัตโนมัติ การแบ่งคะแนนย่อยเป็นเกณฑ์ฝึกของแพลตฟอร์ม

เอกสารข้อสอบเก่ากลางภาคปีการศึกษา 2563 ระบุ 45% และเวลา 3 ชั่วโมง ข้อมูลนี้เป็นประวัติเท่านั้น คำชี้แจงปลายภาคที่แนบระบุ 60% ขอบเขต Set 10–22 เฉพาะหัวข้อที่สอน และ 3 กฎเหล็ก แต่ไม่ระบุจำนวนข้อหรือเวลา จึงไม่กล่าวว่าค่าจำลองเป็นโครงสร้างสอบทางการ

## สร้างและตรวจระบบ

```sh
python3 scripts/build-final.py
python3 scripts/build-masterclass.py
python3 scripts/normalize-site.py
node scripts/normalize-javascript.cjs
python3 scripts/verify-final.py
```

แผนผังเผยแพร่เป็น [JSON ส่วนกลาง](assets/data/curriculum-roadmap.json) และ mirror JavaScript เพื่อรองรับการเปิดไฟล์ตรงโดยไม่ใช้ fetch เนื้อหาเชิงการสอนแก้ใน scripts/masterclass_content.py; โจทย์ที่สอบทานแก้ใน scripts/exam_content.py แล้วสร้างใหม่ตามลำดับข้างต้น

การแปลง JavaScript ใช้ AST จาก Babel ที่มากับ runtime ท้องถิ่นเพื่อเปลี่ยน template literal เป็นการต่อข้อความอย่างปลอดภัย กำหนด EMF_BABEL_BUNDLE เพื่อใช้ runtime ตำแหน่งอื่นได้ ไม่ต้องติดตั้งไลบรารีจากเครือข่าย

ทดสอบเบราว์เซอร์โดยเปิด HTTP server ที่ 127.0.0.1:8765 และ Playwright CLI session ชื่อ em-masterclass แล้วรัน:

```sh
python3 scripts/audit-masterclass.py
python3 scripts/audit-learning-flows.py
```

กำหนด EMF_PLAYWRIGHT_CLI และ EMF_BROWSER_SESSION สำหรับ runtime/session อื่น รายละเอียดผลทดสอบและข้อค้นพบอยู่ใน [บันทึกการปฏิรูปทั้ง 22 บท](docs/MASTERCLASS_IMPLEMENTATION.md)
