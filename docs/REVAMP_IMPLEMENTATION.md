# รายงานการปรับระบบการเรียน 303214

วันที่ตรวจรับ: 13 ตุลาคม 2569

## สิ่งที่เปลี่ยน

- บทเรียน 01–22 มีเนื้อหาหลักใหม่ครบห้าองค์ประกอบ: ภาพกายภาพ การพิสูจน์พร้อมเหตุผล กับดักข้อสอบ การใช้งานวิศวกรรม และห้องทดลอง รวมการพิสูจน์ 179 ขั้น แต่ละบทมี 7–12 ขั้นพร้อมเงื่อนไขของแบบจำลอง
- ปุ่ม **ผังความรู้สะสม** อยู่บน Navbar เพียงตำแหน่งเดียว เปิด Drawer สามแท็บ ข้อมูลมี prerequisites, coreBreakthrough, formulasMastered และ forwardLink ครบ 22 บท บันทึกความเข้าใจเมื่อผู้เรียนยืนยันด้วยตนเอง
- รายการข้อสอบเป็นการ์ดที่มีหัวข้อ คะแนน สถานะงาน และสถานะ Active บนมือถือเลื่อนการ์ดแนวนอน การ์ดใช้ Padding 24px 28px บนเดสก์ท็อป และ 18px 16px บนมือถือ
- ใบงานใช้ worksheet editor พร้อมฟอนต์โค้ดและคำแนะนำ Checklist ใช้การ์ดตรวจงานพร้อมคะแนน ส่วนเฉลยและการเปิดข้อมูลใช้ Accordion ที่มีไอคอนและรองรับแป้นพิมพ์
- แยกห้องสอบ ข้อมูลใบงาน เวลา และประวัติกลางภาคกับปลายภาค การเปิดเฉลยมีสถานะกำกับ และการบันทึกเดิมในโหมดต้นฉบับถูกจัดลำดับใหม่โดยรักษาวิธีทำไว้
- กราฟห้องทดลองใช้แกนพร้อมหน่วย จุดค่าที่เลือก และนิพจน์ชุดเดียวกับผลคำนวณ ความถี่คลื่นเปลี่ยนความยาวคลื่นในแกนระยะจริง ป้าย Canvas ใช้ตัวห้อยและรองรับตัวหนา/ตัวเอียง
- Section เว้นระยะ 48px และปุ่มใต้ Grid เว้นอย่างน้อย 36px แก้ระยะ Anchor บนมือถือให้พ้น Sidebar โดยไม่เว้นพื้นที่เกินจำเป็น
- ไฟล์ CSS/JS ที่ใช้ร่วมกันมี Content Hash เพื่อให้หน้าที่เปิดค้างไม่ใช้รูปแบบหรือโค้ดเก่าจาก Cache

## ความถูกต้องของโจทย์และการประเมิน

ห้องกลางภาคมีต้นฉบับ MID-Q01–MID-Q04 น้ำหนัก 25/20/30/25 รวม 100 คะแนน และคลัง Hayt อีก 7 ข้อ ห้องปลายภาคมี ALL-Q01–ALL-Q12 รวม 12 รายการตามป้ายในไฟล์ และคลังรวม 23 รายการ

การสอบทานยึด [ดัชนีแหล่งข้อมูล](../raw/exam-source-analysis.md) และตรวจหน้าต้นฉบับที่มีสูตร ตัวเลข และภาพประกอบ จุดที่ต้องรักษาไว้มีดังนี้:

- ALL-Q06 คือหน้าต่อของ ALL-Q05; ALL-Q07 คือ curl และ ALL-Q09 คือกระแสการกระจัด ชุดสุ่มรวมสองหน้าแอมแปร์ให้ข้อมูลและปริพันธ์อยู่ด้วยกัน
- ALL-Q08 ใช้สัมประสิทธิ์สนามไฟฟ้า 20 ตามข้อสอบ ต่างจากฉบับสไลด์ที่ใช้ 2 แยกสองฉบับพร้อมผลสนามที่ต่างสิบเท่า
- ALL-Q10 พิมพ์ค่า μ ที่ขัดกับฟาราเดย์ จึงไม่มีค่า k ที่ทำให้ครบทุกสมการ แสดงข้อขัดแย้งและแยกฉบับแก้ตาม Hayt D9.4(b)
- ALL-Q03 ใช้ช่องว่างอวกาศว่าง พิสูจน์ด้วย ε ทั่วไปก่อนคืนค่า ε₀ ตามต้นฉบับ
- โจทย์ MID-Q03 อยู่หน้า PDF 2 และ MID-Q04 เริ่มหน้า 2 ต่อข้อย่อยและรูปหน้า 3 แก้ลิงก์ให้ตรงตำแหน่งจริง
- คะแนนปลายภาค 25 ต่อรายการและคะแนนย่อย Checklist เป็นเกณฑ์ฝึกของเว็บ ไม่ใช่น้ำหนักสอบทางการ สูตรทั่วไปและการวิเคราะห์เป็นฐานของคะแนนส่วนต่อเนื่อง

ระบบเป็น **การประเมินตนเอง** ไม่ได้ตรวจลายมือหรือยืนยันว่ามีการแสดงวิธีบนกระดาษจริง ผู้เรียนต้องใช้เฉลยและ Checklist ตรวจงานของตนเอง

## การแก้เนื้อหาและตรวจซ้ำ

เนื้อหาหลักอยู่ใน [masterclass depth](../scripts/masterclass_depth.py) การเรนเดอร์อยู่ใน [masterclass renderer](../scripts/masterclass_render.py) และการขยายเฉลย/ที่มาอยู่ใน [exam content](../scripts/exam_content.py) แก้แหล่งข้อมูลแล้ว Compile แทนการแก้ HTML ที่สร้างแล้วทีละหน้า

ข้อมูล Roadmap แบบ JSON และสำเนา JavaScript สำหรับเปิดไฟล์โดยตรงสร้างจากข้อมูลชุดเดียวกัน ห้ามแก้สำเนาที่สร้างแล้วแยกจากกัน

```sh
python3 scripts/build-final.py
python3 scripts/build-masterclass.py
python3 scripts/verify-final.py
```

เปิด HTTP Server ในโฟลเดอร์รายวิชาที่พอร์ต 8765 และเปิด Playwright CLI Session ชื่อ em-revamp ก่อนรัน:

```sh
EMF_BROWSER_SESSION=em-revamp python3 scripts/audit-masterclass.py
EMF_BROWSER_SESSION=em-revamp python3 scripts/audit-learning-flows.py
EMF_BROWSER_SESSION=em-revamp python3 scripts/audit-physical-models.py
EMF_BROWSER_SESSION=em-revamp python3 scripts/audit-canvas-labels.py
EMF_BROWSER_SESSION=em-revamp python3 scripts/capture-revamp.py
```

ไฟล์หลักฐานอยู่ใน docs/qa-masterclass และภาพใน output/playwright ตรวจข้อความคณิตศาสตร์ที่แสดงจริงแยกจากชื่อตัวแปรโปรแกรมและชื่อไฟล์ ซึ่งอาจมีขีดล่างตามปกติของโค้ด
