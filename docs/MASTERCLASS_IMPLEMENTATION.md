# การปฏิรูปการเรียนรู้ทั้ง 22 บท

ตรวจเมื่อ 12 ตุลาคม 2569

## ผลที่ใช้งานได้

[พอร์ทัล](../index.html) แยกกลางภาค Sets 01–09 และปลายภาค Sets 10–22 ทุกหน้ามี Roadmap HUD บน Navbar และปุ่มลอยตัว หน้าบทเรียนมีปุ่มใน Sidebar ด้วย

แผนผังเปิดมาแสดงบทปัจจุบันทันที เลือกดูความรู้สะสมตั้งแต่บท 1 ฐานที่ใช้โดยตรง และบทที่นำผลไปใช้ได้ ผัง 22 บทเปิดเพิ่มจากกล่องเลือกบท สถานะเข้าใจแล้วเป็นการยืนยันของผู้เรียน ไม่อนุมานจากการเปิดหน้า บันทึกและย้อนสถานะได้ในเบราว์เซอร์ รองรับ Escape การคืนโฟกัส และปุ่มลูกศรในแท็บ

บทเรียนทั้ง 22 บทเพิ่มคำถามฟิสิกส์ตั้งต้น คำอธิบายภาพในใจ การพิสูจน์ 4 ขั้นพร้อมเหตุผลของแต่ละขั้น จุดตรวจข้อสอบ ฐานความรู้ก่อนหน้า และการเชื่อมกับหม้อแปลง เครื่องจักร หรือสายส่ง แต่ละบทมีสื่อทดลองปรับค่าและบันทึกสิ่งที่ทำนาย/สังเกตได้ สื่อ 3 มิติของบทเดิมและสื่อปลายภาคยังใช้งานร่วมกันได้

บทปลายภาคมีคำอธิบายตามสไลด์หลัก 242 หน้าและเอกสารประกอบ 54 หน้า พร้อมภาพและลิงก์ PDF ตรงหน้า ใบสูตรปลายภาคมี 9 หน้าจริงและ 38 หมวดค้นหาได้

## ห้องสอบและความถูกต้องของแหล่งข้อมูล

- [กลางภาค](../exam-simulator/midterm/index.html): 11 โจทย์ รวม MID-Q01–MID-Q04 และแบบฝึกหัด/Drill จาก Hayt บท 1–4 ชุดข้อสอบเก่ารักษาน้ำหนัก 25/20/30/25
- [ปลายภาค](../exam-simulator/final/index.html): 23 รายการ รวม ALL-Q01–ALL-Q12 และ Drill ที่ตรวจจากตำรา อ่านเสริม D8.8 และ D10.1 ไม่สุ่มเข้าชุดสอบ
- ทุกเฉลยมีสูตรตั้งต้น ขั้นวิเคราะห์ด้วยมือ หน่วย เหตุผลแต่ละขั้น และลิงก์สไลด์/ตำราที่ระบุเลขหน้า PDF
- ALL-Q05 และ ALL-Q06 เป็นตัวอย่างแอมแปร์เดียวกันคนละหน้าต่อเนื่อง โหมดต้นฉบับแสดงตามป้ายทั้งสอง โหมดสุ่มรวมสองหน้านี้เป็นโจทย์เดียวพร้อมขั้นอินทิเกรต
- ALL-Q08 มีสัมประสิทธิ์ E เป็น 20 ส่วนฉบับสไลด์เป็น 2 คลังแยกทั้งสองฉบับพร้อมอธิบายผลต่างสิบเท่า
- ALL-Q10 พิมพ์ μ เป็น 10⁵ ทำให้ฟาราเดย์ขัดแย้งโดยไม่ขึ้นกับ k คลังรักษาข้อมูลนั้นและแสดงการตรวจข้อขัดแย้ง แยกฉบับแก้เป็น 10⁻⁵ ตามสไลด์และ Hayt D9.4
- เฉลย MID-Q01 มีภาพฐานที่เปลี่ยนตามตำแหน่ง ALL-Q11 มีกราฟสนาม E และ H ที่เวลาเป็นศูนย์พร้อมทิศ หน่วย และสเกล

[ดัชนีสอบทานต้นฉบับ](../raw/exam-source-analysis.md) อธิบายแหล่งที่ตรงข้อมูลกับแหล่งที่ใช้ตรวจวิธีแยกกัน ไม่กล่าวว่าโจทย์คนละข้อมูลเป็นโจทย์เดียวกัน มี [ดัชนี JSON](../assets/data/exam-source-map.json) ตรวจความครอบคลุมทุกหน้าและความสัมพันธ์ต่อเนื่อง

Hayt ฉบับที่ 9 บท 10 เป็นสายส่ง ส่วนคลื่นระนาบอยู่บท 11 จึงระบุเลขบทตามไฟล์จริง หัวข้อไม่ได้สอนและ Uniqueness Theorem ไม่ถูกสุ่มสอบ

## การให้คะแนนฝึก

Checklist ประเมินด้วยตนเอง ไม่วิเคราะห์ลายมือหรือพิสูจน์การใช้เครื่องคิดเลข ผู้เรียนต้องตรวจงานในกระดาษแล้วทำเครื่องหมายตามจริง

การขาดสูตรทั่วไปทำให้คะแนนส่วนสูตรเป็นศูนย์ตามคำชี้แจง การไม่ยืนยันปริพันธ์ด้วยมือทำให้ส่วนวิเคราะห์และผลที่พึ่งพาขั้นนั้นไม่ได้คะแนนฝึก ระบบไม่ให้คะแนนคำตอบลอย ๆ โดยไม่มีขั้นตั้งปัญหา วิเคราะห์ และตรวจหน่วย สัดส่วนคะแนนย่อยเป็นเกณฑ์ฝึกที่แพลตฟอร์มกำหนด ไม่ใช่ rubric รายข้อที่อาจารย์ประกาศ

ข้อสอบเก่ากลางภาคปีการศึกษา 2563 ระบุ 100 คะแนน น้ำหนัก 45% และเวลา 3 ชั่วโมง จึงแสดงว่าเป็นข้อมูลในอดีต คำชี้แจงปลายภาคที่แนบระบุ 60% และขอบเขต แต่ไม่ได้กำหนดจำนวนข้อ/เวลา/คะแนนย่อยของข้อสอบปัจจุบัน ชุดสุ่ม 4 หมวด เวลาเริ่มต้น 180 นาที และคะแนนฝึก 25 ต่อรายการปลายภาคจึงระบุว่าเป็นค่าฝึก

ทั้งสองห้องบันทึกงาน Checklist ประวัติเปิดเฉลย และเวลาคงเหลือแยกกัน เวลาที่เริ่มแล้วเดินต่อหลังรีโหลด มีการพักเวลา จบการฝึก และส่งออก JSON โดยไม่ส่งข้อมูลผู้เรียนออกจากเบราว์เซอร์

## โครงสร้างข้อมูลและการสร้างซ้ำ

[curriculum-roadmap.json](../assets/data/curriculum-roadmap.json) มี 22 โหนด: chapterId, title, coreConcepts, keyFormulas, prerequisites, forwardLinks พร้อม anchor, intuition, derivation, application, experiment, examTrap และ sources

เนื้อหาเขียนใน [masterclass_content.py](../scripts/masterclass_content.py) แล้วสร้าง JSON กลางกับ mirror JavaScript สำหรับการเปิดไฟล์ตรงโดยไม่ใช้ fetch [common.js](../assets/js/common.js) สร้าง HUD ร่วมทุกหน้า [masterclass-labs.js](../assets/js/masterclass-labs.js) จัดการสื่อเชิงฟิสิกส์และ reflection

[exam_content.py](../scripts/exam_content.py) สร้างฉบับโจทย์ที่ตรวจต้นฉบับและชุดอ้างอิงร่วมกับตัวสร้างเดิม ห้องสอบใช้ controller เดียวกับ config แยกห้อง โหมด และข้อมูลที่บันทึก การค้นหารวมโจทย์ทั้ง 34 รายการและรหัสแหล่งต้นฉบับ

รันตามลำดับ:

```sh
python3 scripts/build-final.py
python3 scripts/build-masterclass.py
python3 scripts/normalize-site.py
node scripts/normalize-javascript.cjs
python3 scripts/verify-final.py
```

JavaScript ใช้การต่อข้อความแทน template literal ผ่านการแปลง AST ซึ่งรักษาลำดับการประเมินและการแปลงเป็นข้อความ เศษส่วน ดีเทอร์มิแนนต์ ตัวห้อยและเวกเตอร์ใช้ HTML ตามมาตรฐาน
