## ข้อค้นพบที่ต้องรักษา

1. [ใบสูตรที่แนบ](../raw/formu_214_fin_69.pdf) มี 9 หน้าจริง แม้คำสั่งตั้งต้นระบุ 10 หน้า จึงไม่สร้างหน้าที่ไม่มีต้นฉบับ
2. [คำชี้แจงสอบ](../raw/for_Exam_fin_214_69_for_prnt.pdf) ระบุ 60% ขอบเขต และกฎการแสดงงาน แต่ไม่กำหนดเวลาสอบ จำนวนข้อ หรือคะแนนย่อย เวลาตั้งต้น 180 นาที ชุดละ 4 ข้อ และ 25 คะแนนต่อข้อจึงระบุว่าเป็นค่าฝึกซ้อม
3. Checklist เป็นการประเมินด้วยตนเอง ไม่ตรวจลายมือหรือพิสูจน์ว่าผู้เรียนทำอินทิกรัลด้วยมือโดยอัตโนมัติ คะแนนนี้ไม่ใช่คะแนนทางการ
4. Uniqueness Theorem ไม่ถูกนำมาเป็นบทเรียนสอบหรือโจทย์สุ่ม
5. สไลด์ขอบเขตแม่เหล็กใช้กรณีไม่มีกระแสผิว ส่วนสูตรทั่วไปที่มี K เป็นการอ่านเสริม เวกเตอร์ปกติในเว็บกำหนด 2 → 1 เพื่อใช้ผลต่าง H1 − H2 ถ้าชี้ 1 → 2 ต้องสลับผลต่าง
6. คลื่นระนาบใช้ตัวอย่าง Set 22 และการอธิบายจาก Hayt บท 10 ด้วย เพราะเนื้อหานี้ไม่ได้อยู่ครบในบท 5–9 ทั้งหมด
7. ตัวอย่างเทฟลอนใช้ค่า Dn = 20 C/m² ตามต้นฉบับ แม้ให้สนามสูงมาก ไม่เปลี่ยนคำนำหน้าหน่วยเอง
8. สอบทานหน้า Sadiku จากเนื้อหา PDF จริง: ตัวเก็บประจุด้วยลาปลาสหน้า 248, พิสูจน์ลวดตรงหน้า 274, กระแสการกระจัดหน้า 390 และคลื่นหน้า 423–424 ไม่ใช้ค่า offset เลขหน้าคงที่หรือเลขตัวอย่างจากบันทึกวิเคราะห์เดิม
9. ศักย์เวกเตอร์ โพลาไรเซชัน และพลังงานที่เพิ่มจากตำราแสดงว่าเป็นคำอธิบายขยาย ไม่มีการอ้างว่าเป็นสูตรเพิ่มในใบแจกสอบ

ทิศปกติและสมการแมกซ์เวลล์สอบทานเพิ่มเติมกับ [MIT 6.013 Course Notes](https://ocw.mit.edu/courses/6-013-electromagnetics-and-applications-spring-2009/d3be4ea78b036a6362230fb41780cf54_MIT6_013S09_notes.pdf) โดยยึดสไลด์และไฟล์แจกสอบในโครงการเป็นหลัก

## สร้างและตรวจซ้ำ

เปิด terminal ในโฟลเดอร์โครงการ แล้วใช้ Python, Node.js, Poppler และ Pillow ที่มีในเครื่อง

```sh
python3 scripts/build-final.py
python3 scripts/render-sources.py
python3 scripts/normalize-site.py
python3 scripts/verify-final.py
python3 -m http.server 8765 --bind 127.0.0.1
```

เปิดเว็บที่ `http://127.0.0.1:8765` ไม่มีขั้น build ของ framework หรือฐานข้อมูล บทเรียนเป็น HTML อ่านได้แม้ปิด JavaScript ส่วนสื่อจำลองและห้องสอบใช้ JavaScript ในเบราว์เซอร์

ไฟล์เนื้อหาที่ต้องแก้เมื่อปรับการสอนอยู่ใน [สคริปต์สร้าง](../scripts/build-final.py), [บทเรียน](../scripts/final_content.py), [คำอธิบายเพิ่มเติม](../scripts/final_annotations.py), [สูตร](../scripts/final_formulas.py) และ [โจทย์](../scripts/final_problems.py) การสร้างใหม่จะเขียนทับหน้าปลายภาคที่สร้างจากไฟล์เหล่านี้ แต่ไม่เขียนทับเนื้อหาบทเรียนกลางภาค

การทดสอบเบราว์เซอร์และภาพตัวอย่างบันทึกใน [หลักฐาน QA](qa-final/README.md)
