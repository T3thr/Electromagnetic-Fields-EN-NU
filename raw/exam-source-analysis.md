### [ALL-Q01] Continuity Equation: J พุ่งออกในแนวรัศมีและลดลงตาม e⁻ᵗ

- **ตำแหน่งในไฟล์สอบ:** `ข้อสอบทั้งหมด.pdf` หน้า 1–3
- **โจทย์:**
  ```text
  J = (e⁻ᵗ / r) a_r  A/m²
  กำหนดให้ ρ_v → 0 เมื่อ t → ∞
  จงหา:
  (ก) ความหนาแน่นประจุไฟฟ้าเชิงปริมาตร (ρ_v)
  (ข) ความเร็วของความหนาแน่นประจุไฟฟ้าที่เคลื่อนที่ไป (v)
  ```
- **Textbook อ้างอิง:**
  - **[Hayt 9th] Chapter 5 (Conductors and Dielectrics), Section 5.2 (Continuity of Current), หน้า 114–115**
  - **[Sadiku 3rd] Chapter 5 (Electrostatic Boundary-Value Problems), Section 5.8 (Continuity Equation), หน้า 177–180**
- **หลักฐานใน Hayt 9th (หน้า 114–115):**
  > *"As a numerical example illustrating some of the concepts from the last two sections, let us consider a current density that is directed radially outward and decreases exponentially with time, J = (1/r) e⁻ᵗ a_r A/m²... If we assume that ρ_v → 0 as t → ∞, then K(r) = 0, and ρ_v = (1/r²) e⁻ᵗ C/m³... v_r = J_r / ρ_v = r m/s"*
- **เฉลยที่ถูกต้อง:**
  - `ρ_v = (e⁻ᵗ / r²) C/m³`
  - `v = r a_r m/s`

### [ALL-Q04] Biot-Savart Law: พิสูจน์สนามแม่เหล็กจากลวดกระแสตรงยาวอนันต์

- **ตำแหน่งในไฟล์สอบ:** `ข้อสอบทั้งหมด.pdf` หน้า 14–18
- **โจทย์:**
  ```text
  ลวดตรงยาวอนันต์บนแกน z (-∞ ถึง +∞) มีกระแส I ในทิศ +a_z
  จงหาสนามแม่เหล็ก H ณ จุด P(ρ, φ, z=0) โดยใช้กฎของบิโอต์-ซาวารต์
  ```
- **Textbook อ้างอิง:**
  - **[Hayt 9th] Chapter 7 (The Steady Magnetic Field), Section 7.1 (Biot-Savart Law), หน้า 182–186, สมการ (7)–(10), รูป 7.3**

  - อินทิเกรตจาก `α = -π/2` ถึง `+π/2` ได้ `H = (I / (2πρ)) a_φ  A/m`

### [ALL-Q06] Ampère's Law (Point Form): คำนวณ J จาก curl H

- **ตำแหน่งในไฟล์สอบ:** `ข้อสอบทั้งหมด.pdf` หน้า 21–22
- **โจทย์:**
  ```text
  H = x²z a_y - y²x a_z
  จงหาความหนาแน่นกระแสไฟฟ้า J ณ จุด P(2, 3, 4) ในระบบพิกัดฉาก
  ```
- **Textbook อ้างอิง:**
  - **[Hayt 9th] Chapter 7, Section 7.3 (Curl), หน้า 197–204, สมการ (27)–(28)**
  - **[Sadiku 3rd] Chapter 7, Section 7.4 (Curl), หน้า 280–283, Example 7.4**
- **ขั้นตอนการคำนวณ:**
  - `J = ∇ × H = (-x² - y²) a_x + y² a_y + 2xz a_z`
  - แทนจุด P(x=2, y=3, z=4):
    - `J_x = -(2²) - (3²) = -4 - 9 = -13`
    - `J_y = 3² = 9`
    - `J_z = 2(2)(4) = 16`
  - `J = -13 a_x + 9 a_y + 16 a_z  A/m²`

  - **[Hayt 9th] Chapter 2, Section 2.4 (Field of a Line Charge), หน้า 36–39**

### [MID-Q04] ความต่างศักย์และศักย์ไฟฟ้าสัมบูรณ์ (25 คะแนน)

- **ตำแหน่งในไฟล์สอบ:** `ข้อสอบเก่า.pdf` หน้า 2–3 (ข้อ 4)

  ```text
  4.1 จงหาความต่างศักย์ V_AB ระหว่างจุด A (รัศมี r = r_A) และจุด B (รัศมี r = r_B)
      ท่ามกลางฟลักซ์ไฟฟ้า D = (a / r) a_r  (หรือ D = (Q / 4πr²) a_r)
  4.2 ถ้า r_A < r_B ความต่างศักย์ V_AB มีค่าเป็นบวกหรือลบ ทำไมจึงเป็นเช่นนั้น พร้อมยกอุปมาประกอบ
  4.3 จงหาศักย์ไฟฟ้าสัมบูรณ์ (Absolute Potential) ในปัญหานี้
  ```

  - **[Sadiku 3rd] Chapter 4, Section 4.7 (Electric Potential), หน้า 127–132, สมการ (4.31)–(4.36)**
- **คำอธิบายแนวคิดตาม Textbook:**
  - **ข้อ 4.1:** `E = D / ε₀ = (a / ε₀ r) a_r`
    - `V_AB = -∫_B^A E · dL = -∫_{r_B}^{r_A} (a / ε₀ r) dr = (a / ε₀) ln(r_B / r_A)`
  - **ข้อ 4.2:** เมื่อ `r_A < r_B` จะได้ `r_B / r_A > 1` ทำให้ `ln(r_B / r_A) > 0` ดังนั้น `V_AB > 0` (เป็นบวก)
    - **อุปมาอธิบายงาน:** จุด A อยู่ใกล้ประจุบวกมากกว่าจุด B ย่อมมีศักย์สูงกว่า การเคลื่อนประจุทดสอบบวกจาก B เข้าใกล้จุด A ต้องทำงานต้านแรงผลักของสนามไฟฟ้า เปรียบเหมือนการเข็นลูกหินขึ้นเขาไปยังจุดที่สูงกว่า
  - **ข้อ 4.3:** ศักย์ไฟฟ้าสัมบูรณ์กำหนดโดยเลือกจุดอ้างอิงที่อนันต์ `r_B → ∞` โดย `V(∞) = 0`
    - สำหรับประจุจุด `D = (Q / 4πr²) a_r`: `V(r) = Q / (4πε₀ r)`
