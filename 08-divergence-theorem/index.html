บทที่ 8: ไดเวอร์เจนซ์และทฤษฎีบทไดเวอร์เจนซ์ (Divergence & Divergence Theorem)

การพิสูจน์การกระจายอนุกรมเทย์เลอร์บนกล่องส่วนย่อย 6 ด้าน, นิยามตัวดำเนินการไดเวอร์เจนซ์ ∇ • D, สมการของแมกซ์เวลล์ข้อที่ 1 ในรูปแบบจุด (Point Form of Gauss's Law: ∇ • D = ρv), สูตรใน 3 ระบบพิกัด และทฤษฎีบทไดเวอร์เจนซ์

วัตถุประสงค์การเรียนรู้ประจำบท (Learning Objectives):

  1. เข้าใจการพิสูจน์ทางคณิตศาสตร์ของการประยุกต์กฎของเกาส์กับปริมาตรส่วนย่อย Δv = Δx Δy Δz ด้วยการประมาณค่าเชิงเส้นของอนุกรมเทย์เลอร์ (Taylor Series Linear Approximation) ครบทั้ง 6 ผิว
  2. เข้าใจนิยามทางกายภาพของ ไดเวอร์เจนซ์ (Divergence, div D หรือ ∇ • D) ในฐานะการลู่ออกของฟลักซ์ต่อหนึ่งหน่วยปริมาตรเมื่อปริมาตรลดลงเข้าใกล้ศูนย์
  3. จดจำและประยุกต์ สมการของแมกซ์เวลล์ข้อที่ 1 (Maxwell's First Equation): ∇ • D = ρv ในการหาความหนาแน่นประจุเชิงปริมาตรจากสนามฟลักซ์ที่กำหนด
  4. คำนวณไดเวอร์เจนซ์ในระบบพิกัดฉาก (Cartesian), ทรงกระบอก (Cylindrical), และทรงกลม (Spherical) ได้อย่างแม่นยำ
  5. ประยุกต์ ทฤษฎีบทไดเวอร์เจนซ์ (Divergence Theorem) เพื่อแปลงระหว่างอินทิกรัลผิวปิด ∮S D • ds และอินทิกรัลปริมาตร ∫v (∇ • D) dv

1. การประยุกต์กฎของเกาส์กับปริมาตรส่วนย่อยขนาดเล็ก (Infinitesimal Differential Volume)

ในบทที่ 7 เราได้ศึกษากฎของเกาส์ใน รูปแบบอินทิกรัล (Integral Form) ซึ่งเหมาะสมกับการแก้ปัญหาที่มีความสมมาตรสูงในระดับมหภาค (Macroscopic Scale) แต่หากสนามเวกเตอร์ D มีความแปรผันตามตำแหน่งอย่างซับซ้อน เราจำเป็นต้องพิจารณากฎของเกาส์ใน ระดับจุลภาค ณ จุดใดจุดหนึ่ง (Point Form / Differential Form)

พิจารณากล่องปริมาตรปิดขนาดเล็ก Δv = Δx Δy Δz ซึ่งมีจุดศูนย์กลางอยู่ที่จุด P(x₀, y₀, z₀) ในอวกาศ 3 มิติ และมีค่าความหนาแน่นฟลักซ์ไฟฟ้า ณ จุด P เป็น D₀ = Dx0 ax + Dy0 ay + Dz0 az

2. การพิสูจน์การกระจายอนุกรมเทย์เลอร์ครบทั้ง 6 ด้าน (Complete Taylor Series Proof)

การหาฟลักซ์ไฟฟ้ารวมที่พุ่งออกจากกล่องปิด ∮S D • ds จะต้องอินทิเกรตรวมฟลักซ์ที่ผ่านผิวทั้ง 6 ด้าน:

∮S D • ds = ( ∫front + ∫back ) + ( ∫left + ∫right ) + ( ∫top + ∫bottom )
คู่ที่ 1: ผิวหน้า (Front) และผิวหลัง (Back)

• ผิวหน้า (Front) ตั้งฉากกับแกน x อยู่ที่ x = x₀ + Δx/2 และมี dsfront = Δy Δz ax

• ผิวหลัง (Back) ตั้งฉากกับแกน x อยู่ที่ x = x₀ - Δx/2 และมี dsback = -Δy Δz ax

ใช้การกระจายอนุกรมเทย์เลอร์เชิงเส้นประมาณค่า Dx ณ ผิวทั้งสอง:

Dx,front ≈ Dx0 + Δx2 ∂Dx∂x
Dx,back ≈ Dx0 - Δx2 ∂Dx∂x

คำนวณผลรวมฟลักซ์ผ่านผิวหน้าและผิวหลัง:

∫front D • ds = Dx,front Δy Δz ≈ [ Dx0 + Δx2 ∂Dx∂x ] Δy Δz
∫back D • ds = -Dx,back Δy Δz ≈ [ -Dx0 + Δx2 ∂Dx∂x ] Δy Δz

( ∫front + ∫back ) = ∂Dx∂x Δx Δy Δz
คู่ที่ 2 และ 3: ซ้าย-ขวา และ บน-ล่าง

ด้วยกระบวนการเดียวกันบนแกน y และแกน z:

( ∫right + ∫left ) = ∂Dy∂y Δx Δy Δz
( ∫top + ∫bottom ) = ∂Dz∂z Δx Δy Δz

เมื่อนำฟลักซ์ทั้ง 6 ด้านมารวมกันทั้งหมด:

∮S D • ds = [ ∂Dx∂x + ∂Dy∂y + ∂Dz∂z ] Δx Δy Δz = [ ∂Dx∂x + ∂Dy∂y + ∂Dz∂z ] Δv = Qenc

3. นิยามทางคณิตศาสตร์และกายภาพของไดเวอร์เจนซ์ (Definition of Divergence)

นำปริมาตร Δv หารตลอดทั้งสองข้าง แล้วเทคลิมิตเมื่อปริมาตรมีขนาดเล็กลงเรื่อยๆ จนยุบตัวกลายเป็นจุด (Δv → 0):

นิยามทางการของตัวดำเนินการไดเวอร์เจนซ์ (Divergence Definition)
div D = ∇ • D = limΔv→0 ∮S D • dsΔv
ความหมายทางกายภาพ: ไดเวอร์เจนซ์ของสนามเวกเตอร์ D ณ จุดใดๆ คือ การไหลออกสุทธิของฟลักซ์จากผิวปิดขนาดเล็กต่อหนึ่งหน่วยปริมาตร เมื่อปริมาตรนั้นหดตัวลงเข้าใกล้ศูนย์
(The divergence of the vector flux density D is the outflow of flux from a small closed surface per unit volume as the volume shrinks to zero.)

4. สมการของแมกซ์เวลล์ข้อที่ 1 ในรูปแบบจุด (Maxwell's First Equation / Point Form)

เมื่อแทนความสัมพันธ์ limΔv→0 [ Qenc / Δv ] = ρv ลงในนิยามไดเวอร์เจนซ์ เราจะได้สมการที่เป็นหนึ่งในเสาหลักที่สำคัญที่สุดของวิชาแม่เหล็กไฟฟ้า:

สมการของแมกซ์เวลล์ข้อที่ 1 (Maxwell's 1st Equation / Point Form of Gauss's Law)
∇ • D = ρv        (หรือ   ∇ • E = ρvε₀   ในอวกาศว่าง)
ความหมายทางกายภาพของสมการแมกซ์เวลล์ข้อที่ 1:
  • เมื่อ ∇ • D > 0 (เป็นบวก): ณ จุดนั้นมีประจุบวก ρv > 0 ทำหน้าที่เป็น แหล่งกำเนิดฟลักซ์ (Source) มีเส้นฟลักซ์แผ่พุ่งออกจากจุดนั้นสุทธิ
  • เมื่อ ∇ • D < 0 (เป็นลบ): ณ จุดนั้นมีประจุลบ ρv < 0 ทำหน้าที่เป็น แหล่งดูดกลืนฟลักซ์ (Sink) มีเส้นฟลักซ์พุ่งเข้าหาจุดนั้นสุทธิ
  • เมื่อ ∇ • D = 0 (เป็นศูนย์): ณ จุดนั้นไม่มีประจุไฟฟ้าสุทธิ ρv = 0 ฟลักซ์ที่ไหลเข้าย่อมไหลออกเท่ากันพอดี เรียกว่า สนามโซลินอยด์ (Solenoidal / Incompressible Field)

5. สูตรตัวดำเนินการเดลและไดเวอร์เจนซ์ใน 3 ระบบพิกัดสากล

ตัวดำเนินการเดล (Del Operator ∇) ในระบบพิกัดฉากนิยามเป็น ∇ = ax ∂∂x + ay ∂∂y + az ∂∂z เมื่อนำไปทำ Dot Product กับสนามเวกเตอร์ D จะได้สูตรใน 3 ระบบพิกัดดังนี้:

ระบบพิกัด (Coordinate System) สูตรไดเวอร์เจนซ์ ∇ • D (Divergence Formula) จุดที่ต้องระวังในการหาอนุพันธ์
1. พิกัดฉาก (Cartesian)
∇ • D = ∂Dx∂x + ∂Dy∂y + ∂Dz∂z
ดิฟตรงตามแนวแกนแต่ละตัวแปร
2. พิกัดทรงกระบอก (Cylindrical)
∇ • D = 1ρ ∂∂ρ(ρ Dρ) + 1ρ ∂Dϕ∂ϕ + ∂Dz∂z
ต้องคูณ ρ เข้ากับ Dρ ก่อนดิฟ แล้วจึงหารด้วย ρ
3. พิกัดทรงกลม (Spherical)
∇ • D = 1r² ∂∂r(r² Dr) + 1r sin θ ∂∂θ(Dθ sin θ) + 1r sin θ ∂Dϕ∂ϕ
พจน์แรกคูณ r² ก่อนดิฟ, พจน์ที่สองคูณ sin θ ก่อนดิฟ

6. ทฤษฎีบทไดเวอร์เจนซ์ (Divergence Theorem / Gauss-Ostrogradsky Theorem)

ทฤษฎีบทไดเวอร์เจนซ์ เป็นสะพานเชื่อมโยงทางคณิตศาสตร์ที่สำคัญที่สุดระหว่าง มุมมองมหภาคบนผิวปิด (Surface Flux Integral) และ มุมมองจุลภาคภายในปริมาตร (Volume Integral of Divergence):

ทฤษฎีบทไดเวอร์เจนซ์ (Divergence Theorem)
∮S D • ds = ∫vol (∇ • D) dv = Qenc
ประโยชน์ในทางวิศวกรรม: ช่วยให้เราสามารถเปลี่ยนการอินทิเกรตฟลักซ์บนผิวปิด 6 ด้าน (เช่น กล่องสี่เหลี่ยม หรือ ทรงกระบอกที่มีฝาปิดหัวท้าย) ให้กลายเป็นการอินทิเกรตเชิงปริมาตรเพียง 1 เทอมได้อย่างสะดวกและรวดเร็ว

7. ตัวอย่างโจทย์และการบ้านจากเอกสารคำสอนอาจารย์ (Lecture Set 8)

ตัวอย่างในห้องเรียน (Lecture Set 8 Slide 28)

โจทย์: กำหนดสนามความหนาแน่นฟลักซ์ไฟฟ้า D = e⁻ˣ sin y ax - e⁻ˣ cos y ay + 2z az C/m² จงหาความหนาแน่นประจุเชิงปริมาตร ρv ณ จุดกำเนิด (0, 0, 0)

วิธีทำอย่างละเอียด:

  1. เขียนสูตรสมการแมกซ์เวลล์ข้อที่ 1 (Formula-First):
    ρv = ∇ • D = ∂Dx∂x + ∂Dy∂y + ∂Dz∂z
  2. หาอนุพันธ์ย่อยทีละองค์ประกอบ:
    ∂Dx∂x = ∂∂x(e⁻ˣ sin y) = -e⁻ˣ sin y
    ∂Dy∂y = ∂∂y(-e⁻ˣ cos y) = -e⁻ˣ (-sin y) = +e⁻ˣ sin y
    ∂Dz∂z = ∂∂z(2z) = 2
  3. รวมค่าไดเวอร์เจนซ์:
    ∇ • D = (-e⁻ˣ sin y) + (e⁻ˣ sin y) + 2 = 2 C/m³
  4. แทนค่า ณ จุดกำเนิด (0, 0, 0):
    ρv(0, 0, 0) = 2 C/m³    (มีค่าคงที่เท่ากับ 2 C/m³ ทุกๆ จุดในอวกาศ)

ตอบ: ความหนาแน่นประจุเชิงปริมาตร ณ จุดกำเนิดมีค่าเท่ากับ ρv = 2 C/m³

การบ้าน 10 คะแนนเต็ม (Lecture Set 8 Slide 29)

โจทย์: จงหาความหนาแน่นประจุไฟฟ้าเชิงปริมาตร ρv ณ จุด P(2, 3, -1) ในระบบพิกัดฉาก เมื่อกำหนดความหนาแน่นฟลักซ์ไฟฟ้า D = (2xyz - y²) ax + (x²z - 2xy) ay + x²y az C/m²

วิธีทำอย่างสมบูรณ์:

  1. เขียนสูตรตั้งต้น:
    ρv = ∇ • D = ∂Dx∂x + ∂Dy∂y + ∂Dz∂z
  2. หาอนุพันธ์ย่อยในรูปตัวแปรก่อนแทนค่าตัวเลข:
    ∂Dx∂x = ∂∂x(2xyz - y²) = 2yz
    ∂Dy∂y = ∂∂y(x²z - 2xy) = -2x
    ∂Dz∂z = ∂∂z(x²y) = 0
  3. รวมสมการทั่วไปของ ρv:
    ρv(x, y, z) = 2yz - 2x + 0 = 2yz - 2x C/m³
  4. แทนค่าพิกัดจุด P(x=2, y=3, z=-1):
    ρv(2, 3, -1) = 2(3)(-1) - 2(2) = -6 - 4 = -10 C/m³

ตอบ: ความหนาแน่นประจุไฟฟ้าเชิงปริมาตร ณ จุด P มีค่าเท่ากับ ρv = -10 C/m³ (เป็นแหล่งดูดกลืน Sink)

8. ตัวอย่างโจทย์ฝึกทักษะระดับ Textbook (Hayt & Buck Drill Problems)

Drill Problem 3.6

กำหนดสนามความหนาแน่นฟลักซ์ในระบบพิกัดทรงกระบอก D = [ (2ρ + z²) sin ϕ ] aρ + ρ cos ϕ aϕ + 2ρz sin ϕ az C/m² จงหาค่าไดเวอร์เจนซ์ ∇ • D ณ จุด P(ρ=2, ϕ=110°, z=-1)

วิธีทำ:

  1. เขียนสูตรไดเวอร์เจนซ์ในระบบพิกัดทรงกระบอก:
    ∇ • D = 1ρ ∂∂ρ(ρ Dρ) + 1ρ ∂Dϕ∂ϕ + ∂Dz∂z
  2. หาทีละพจน์:
    • ρ Dρ = (2ρ² + ρz²) sin ϕ    ⇒    ∂∂ρ(ρ Dρ) = (4ρ + z²) sin ϕ
    • 1ρ ∂∂ρ(ρ Dρ) = [ 4 + z²ρ ] sin ϕ
    • 1ρ ∂Dϕ∂ϕ = 1ρ ∂∂ϕ(ρ cos ϕ) = -sin ϕ
    • ∂Dz∂z = ∂∂z(2ρz sin ϕ) = 2ρ sin ϕ
  3. รวมทุกพจน์:
    ∇ • D = [ 4 + z²ρ - 1 + 2ρ ] sin ϕ = [ 3 + z²ρ + 2ρ ] sin ϕ
  4. แทนค่า ณ จุด P(ρ=2, ϕ=110°, z=-1):
    ∇ • D = [ 3 + (-1)²2 + 2(2) ] sin(110°) = [ 3 + 0.5 + 4 ] (0.9397) = (7.5)(0.9397) = 7.048 C/m³

ตอบ: ∇ • D = 7.048 C/m³

9. แบบประเมินความเข้าใจด้วยตนเอง (Self-Assessment Quiz)

คำถามที่ 1: ความหมายทางฟิสิกส์ของ ∇ • D = 0

5 คะแนน

หากการคำนวณไดเวอร์เจนซ์ของสนามฟลักซ์ไฟฟ้าในบริเวณหนึ่งได้ค่าเป็น ∇ • D = 0 ตลอดทั่วทั้งบริเวณ ข้อสรุปใดถูกต้องที่สุด?

บริเวณนั้นไม่มีสนามไฟฟ้าเลย (E = 0)
บริเวณนั้นไม่มีความหนาแน่นประจุสุทธิ (ρ_v = 0) ฟลักซ์ที่ไหลเข้าเท่ากับไหลออก
บริเวณนั้นเป็นตัวนำยิ่งยวดที่สะสมประจุอนันต์
สนามไฟฟ้าในบริเวณนั้นมีทิศทางชี้พุ่งออกจากจุดกำเนิดเสมอ

คำถามที่ 2: การคำนวณไดเวอร์เจนซ์ในพิกัดทรงกระบอก

5 คะแนน

ในพิกัดทรงกระบอก พจน์แรกของไดเวอร์เจนซ์ (1/ρ) ∂(ρ D_ρ)/∂ρ มีขั้นตอนที่ถูกต้องอย่างไร?

ดิฟ D_ρ เทียบกับ ρ ก่อน แล้วค่อยคูณด้วย ρ²
ดิฟ D_ρ เทียบกับ ρ ตรงๆ โดยไม่ต้องนำ ρ มาเกี่ยวข้อง
คูณตัวแปร ρ เข้ากับ D_ρ ก่อน แล้วจึงหาอนุพันธ์เทียบกับ ρ จากนั้นหารผลลัพธ์ด้วย ρ
อินทิเกรต D_ρ เทียบกับ dρ แล้วหารด้วย 2π
