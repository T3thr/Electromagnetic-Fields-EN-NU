303214 สนามแม่เหล็กไฟฟ้า 1 อ้างอิง Hayt & Buck (9th Edition)

คลังความรู้และระบบการเรียนรู้วิชาสนามแม่เหล็กไฟฟ้า 1

ระบบรวบรวมเนื้อหาการสอนรายวิชา 303214 (Electromagnetic Fields I) ครอบคลุมทั้งภาคทฤษฎีไฟฟ้าสถิต สนามแม่เหล็กสถิต สนามแม่เหล็กไฟฟ้าแปรตามเวลา สมการแมกซ์เวลล์ พร้อมโปรแกรมจำลองทัศนภาพ 3 มิติเชิงปฏิสัมพันธ์

คำอธิบายรายวิชาและโครงสร้างความรู้ (Course Architecture)

วิชาสนามแม่เหล็กไฟฟ้า 1 เป็นรากฐานสำคัญที่สุดของวิศวกรรมไฟฟ้า โดยศึกษากฎทางฟิสิกส์และคณิตศาสตร์เวกเตอร์ชั้นสูงที่อธิบายปฏิสัมพันธ์ระหว่างประจุไฟฟ้า กระแสไฟฟ้า แรงดันไฟฟ้า และพลังงานคลื่นแม่เหล็กไฟฟ้า โครงสร้างรายวิชาแบ่งออกเป็น 2 ช่วงการศึกษาหลัก:

1. ส่วนกลางภาค: ไฟฟ้าสถิตและระบบพิกัด 3 มิติ (Sets 1–9)
ศึกษาการวิเคราะห์เวกเตอร์ 3 ระบบพิกัด, แรงระหว่างประจุของคูลอมบ์, ความเข้มสนามไฟฟ้า E, ฟลักซ์ไฟฟ้า D, กฎของเกาส์, ไดเวอร์เจนซ์ ∇ • D และศักย์ไฟฟ้า V
2. ส่วนปลายภาค: ตัวนำ แม่เหล็กสถิต และสมการแมกซ์เวลล์ (Sets 10–22)
ศึกษากระแสและความหนาแน่น J, เงื่อนไขขอบเขต, สมการปัวซง-ลาปลาซ ∇²V, กฎบิโอต์-ซาวารต์, กฎแอมแปร์ ∮ H • dl, เคิร์ล ∇ × H, กระแสแทนที่ Jd และสมการแมกซ์เวลล์

1. สารบัญเนื้อหาส่วนกลางภาค (Midterm Syllabus · Sets 01–09)

น้ำหนัก 45%
ชุดที่ ชื่อบทเรียน ขอบเขตเนื้อหาและหัวข้อสำคัญ เข้าสู่บทเรียน
Set 01 พีชคณิตเวกเตอร์และระบบพิกัดฉาก ปริมาณสเกลาร์-เวกเตอร์, เวกเตอร์บอกตำแหน่งและระยะทาง, ผลคูณจุด (Dot), ผลคูณไขว้ (Cross), ส่วนย่อยเชิงอนุพันธ์ dl, ds, dv ศึกษาบทเรียน
Set 02 ระบบพิกัดทรงกระบอก ตัวแปร (ρ, ϕ, z), ผิวตัดกัน 3 ผิว, เวกเตอร์ฐาน (aρ, aϕ, az), เมทริกซ์การแปลงเวกเตอร์ [Arc], การแปลงสนามเวกเตอร์ ศึกษาบทเรียน
Set 03 ระบบพิกัดทรงกลม ตัวแปร (r, θ, ϕ), ข้อจำกัดของยูนิตเวกเตอร์ ar, aθ, aϕ และการแปลงเวกเตอร์ A ณ จุด P (เนื้อหาข้อสอบข้อ 1) ศึกษาบทเรียน
Set 04 กฎของคูลอมบ์และแรงระหว่างประจุ แรงระหว่างจุดประจุ F = k (Q1Q2 / R²) aR, การรวมแรงเวกเตอร์ Fnet และการหาจุดสมดุลแรง (เนื้อหาข้อสอบข้อ 2) ศึกษาบทเรียน
Set 05 ความเข้มสนามไฟฟ้า E สนามไฟฟ้าจากประจุจุด เส้น ผิว ปริมาตร และการอินทิเกรตลวดประจุจำกัดด้วยตรีโกณมิติ z = 3 tan ψ (เนื้อหาข้อสอบข้อ 3) ศึกษาบทเรียน
Set 06 ฟลักซ์ไฟฟ้าและความหนาแน่นฟลักซ์ D การทดลองทรงกลมตัวนำซ้อนของฟาราเดย์, ฟลักซ์รวม Ψ = Qenc, ความสัมพันธ์ D = ε₀ E ในอวกาศว่าง ศึกษาบทเรียน
Set 07 กฎของเกาส์ สมการอินทิกรัล ∮ D • ds = Qenc และการประยุกต์ผิวเกาส์เซียนสมมาตร 3 รูปแบบ (ทรงกลม, ทรงกระบอก, แผ่นระนาบ) ศึกษาบทเรียน
Set 08 ไดเวอร์เจนซ์และทฤษฎีบทไดเวอร์เจนซ์ สมการแมกซ์เวลล์ข้อที่ 1 (∇ • D = ρv), สูตรไดเวอร์เจนซ์ใน 3 ระบบพิกัด และทฤษฎีบทไดเวอร์เจนซ์ ศึกษาบทเรียน
Set 09 ศักย์ไฟฟ้าและพลังงาน ความต่างศักย์ VAB = -∫ E • dl, เกรเดียนต์ E = -∇V และอุปมาฟิสิกส์เครื่องหมายศักย์ไฟฟ้า (เนื้อหาข้อสอบข้อ 4) ศึกษาบทเรียน

2. สารบัญเนื้อหาส่วนปลายภาค (Final Syllabus · Sets 10–22 ตามชุดสไลด์อาจารย์)

อยู่ระหว่างการจัดเตรียม
ชุดที่ ชื่อชุดสไลด์บรรยาย (Lecture Set) ขอบเขตเนื้อหาและหัวข้อสำคัญ สถานะ
Set 10 Current and Current Density กระแสไฟฟ้า I, ความหนาแน่นกระแส J, สมการความต่อเนื่องของกระแส ∇ • J = -∂ρv/∂t, สภาพนำไฟฟ้า σ และกฎของโอห์มแบบจุด เตรียมเปิดตัว
Set 11 Metallic Conductors and Dielectrics สมบัติของตัวนำในสถิตไฟฟ้า, สนามภายในตัวนำ E = 0, วัสดุไดอิเล็กทริก, โพลาไรเซชัน P, สภาพยอมสัมพัทธ์ εr เตรียมเปิดตัว
Set 12 Boundary Conditions เงื่อนไขขอบเขตระหว่างตัวนำ-ไดอิเล็กทริก (Et = 0, DN = ρs) และไดอิเล็กทริก-ไดอิเล็กทริก (Et1 = Et2, DN1 - DN2 = ρs) เตรียมเปิดตัว
Set 13 Capacitance and Electrostatic Energy นิยามความจุไฟฟ้า C = Q/V, การคำนวณความจุไฟฟ้าแผ่นขนาน ทรงกระบอก ทรงกลม และพลังงานสะสม WE = (1/2) ∫ ε E² dv เตรียมเปิดตัว
Set 14 Poisson's and Laplace's Equations สมการของปัวซง ∇²V = -ρv/ε, สมการของลาปลาซ ∇²V = 0, ทฤษฎีบทเอกลักษณ์ และการแก้สมการค่าขอบเขต 1 มิติ เตรียมเปิดตัว
Set 15 The Steady Magnetic Field & Biot-Savart กฎของบิโอต์-ซาวารต์ dH = (I dl × aR)/(4π R²), สนามแม่เหล็กจากเส้นกระแสตรงอนันต์และวงแหวนกระแส เตรียมเปิดตัว
Set 16 Ampere's Circuital Law กฎวงรอบของแอมแปร์ ∮ H • dl = Ienc, การประยุกต์กับเส้นกระแส สายเคเบิลโคแอกเชียล แผ่นกระแส และขดลวดโซเลนอยด์ เตรียมเปิดตัว
Set 17 Curl and Stokes' Theorem ตัวดำเนินการเคิร์ล ∇ × H ใน 3 ระบบพิกัด, ทฤษฎีบทของสโตกส์ ∮ H • dl = ∫ (∇ × H) • ds และสมการแมกซ์เวลล์ ∇ × H = J เตรียมเปิดตัว
Set 18 Magnetic Flux Density & Gauss for Magnetism ความหนาแน่นฟลักซ์แม่เหล็ก B = μ₀ H, ฟลักซ์แม่เหล็ก Φ = ∫ B • ds, กฎของเกาส์สำหรับแม่เหล็ก ∇ • B = 0 (ไม่มีขั้วแม่เหล็กเดี่ยว) เตรียมเปิดตัว
Set 19 Maxwell's Equations for Static Fields สรุปสมการแมกซ์เวลล์สำหรับสนามไฟฟ้าและแม่เหล็กสถิตทั้ง 4 ข้อ ทั้งในรูปเชิงอนุพันธ์ (Point form) และรูปอินทิกรัล (Integral form) เตรียมเปิดตัว
Set 20 Time-Varying Fields & Faraday's Law กฎการเหนี่ยวนำของฟาราเดย์ emf = -dΦ/dt, แรงเคลื่อนไฟฟ้าจากการเคลื่อนที่ (Motional emf) และ ∇ × E = -∂B/∂t เตรียมเปิดตัว
Set 21 Displacement Current แนวคิดกระแสแทนที่ของแมกซ์เวลล์ Jd = ∂D/∂t, การแก้ไขกฎของแอมแปร์ ∇ × H = J + ∂D/∂t เตรียมเปิดตัว
Set 22 Maxwell's Equations for Time-Harmonic Fields สมการแมกซ์เวลล์ฉบับสมบูรณ์สำหรับสนามฮาร์มอนิกไซน์, เวกเตอร์เฟสเซอร์ และการกำเนิดคลื่นแม่เหล็กไฟฟ้าในระนาบ เตรียมเปิดตัว
