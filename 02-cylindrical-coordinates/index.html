Set 1 · พีชคณิตเวกเตอร์

01 · สร้างภาพในใจก่อนใช้สมการ

รอบลวดตรงหรือแกนเครื่องจักร รูปร่างซ้ำเดิมทุกมุม จึงสะดวกที่จะวัดระยะออกจากแกนด้วย ρ แทน x และ y แต่ฐานรัศมีของคนที่อยู่คนละด้านของแกนชี้คนละทิศ ตัวเลของค์ประกอบเท่ากันจึงไม่ได้หมายถึงลูกศรฉากเท่ากัน

เดินเพิ่มมุมเล็ก dϕ ที่รัศมีไกลกว่า จะเดินเป็นระยะทางมากกว่า นี่คือเหตุที่ ρ ต้องอยู่ในส่วนย่อยความยาว พื้นที่ ปริมาตร และตัวดำเนินการอนุพันธ์ ไม่ใช่ตัวประกอบที่เพิ่มมาจากการท่องจำ

ขอบเขตแบบจำลอง: ρ≥0 และใช้มุมเป็นเรเดียนในส่วนย่อยและอนุพันธ์

02 · พิสูจน์ทีละบรรทัดพร้อมเหตุผล

01 นิยามตำแหน่งทั่วไป

r(ρ,ϕ,z)=ρ cosϕax+ρ sinϕay+zaz

เหตุใดจึงแปลงรูปเช่นนี้? นี่คือเวกเตอร์จากจุดกำเนิดไปยังจุดสังเกต ไม่ใช่เวกเตอร์สนามที่ต้องการแปลง

02 หาแนวเพิ่มรัศมี

∂r∂ρ=cosϕax+sinϕay=aρ

เหตุใดจึงแปลงรูปเช่นนี้? ถือมุมและความสูงคงที่แล้วดิฟเฟอเรนเชียลตามรัศมี เวกเตอร์ที่ได้มีขนาดหนึ่ง

03 หาแนวเพิ่มมุมและทำให้เป็นหน่วย

∂r∂ϕ=ρ(−sinϕax+cosϕay); aϕ=1ρ∂r∂ϕ

เหตุใดจึงแปลงรูปเช่นนี้? อนุพันธ์ตามมุมมีขนาด ρ ต้องหารออกก่อนเรียกว่าเวกเตอร์หน่วย ทิศเพิ่ม ϕ ทวนเข็มเมื่อมองจาก +z

04 แปลงเวกเตอร์ด้วยการฉาย

Aρ=Axcosϕ+Aysinϕ
Aϕ=−Axsinϕ+Aycosϕ; Az คงเดิม

เหตุใดจึงแปลงรูปเช่นนี้? ฉาย A บนฐานที่ตำแหน่งนั้น ใช้มุมของจุด P ที่โจทย์กำหนด ไม่ใช้มุมของลูกศรสนาม

05 ดิฟเฟอเรนเชียลตำแหน่ง

dl=aρdρ+ρaϕdϕ+azdz

เหตุใดจึงแปลงรูปเช่นนี้? กฎลูกโซ่รวมอนุพันธ์ตามพิกัดทั้งสาม ให้ด้านเล็กของกล่องโค้งยาว dρ, ρdϕ และ dz

06 ประกอบผิวและปริมาตร

dsρ=ρdϕdzaρ; dsϕ=dρdzaϕ; dsz=ρdρdϕaz
dv=ρdρdϕdz

เหตุใดจึงแปลงรูปเช่นนี้? แต่ละผิวใช้ผลคูณด้านที่อยู่บนผิวนั้น ส่วนปริมาตรใช้ผลคูณทั้งสามด้าน กล่องเล็กจึงอธิบาย Jacobian ได้

07 ตรวจกรณีบนแกน y บวก

ϕ=90° ⇒ aρ=ay; aϕ=−ax
aρ × aϕ=az

เหตุใดจึงแปลงรูปเช่นนี้? ทิศสัมผัสต้องชี้ไปทาง x ลบจึงเพิ่มมุมต่อได้ ตรวจลำดับฐานด้วยมือขวา

03 · กับดักที่ทำให้เสียคะแนน

  • ใช้ atan2 เพื่อรักษาควอดรันต์; arctan(y/x) อย่างเดียวแยกด้านตรงข้ามไม่ได้

04 · สนามนี้อยู่ในงานวิศวกรรมอย่างไร

สนามรอบบัสบาร์ทรงกระบอกและสายโคแอกเชียลมีสมมาตรตรงกับฐานนี้ การเลือกวงรัศมีคงที่จะทำให้การอินทิเกรตแอมแปร์เหลือเพียงมุมเดียว

ในการวิเคราะห์เครื่องจักรหมุน องค์ประกอบรัศมีและสัมผัสช่วยแยกแรงกดผิวออกจากแรงที่สร้างแรงบิดได้ แม้แบบจำลองจริงจะต้องรวมวัสดุและช่องอากาศเพิ่มเติม

ระบบพิกัด 3 มิติสำหรับโครงสร้างสมมาตรเชิงทรงกระบอก: ตัวแปร (ρ, ϕ, z), ผิวตัดกัน 3 ผิว, เวกเตอร์หนึ่งหน่วยฐาน (aρ, aϕ, az), ส่วนย่อยเชิงอนุพันธ์, การแปลงพิกัดจุด, การแปลงสนามเวกเตอร์ และตารางผลคูณจุด Table 1.1

วัตถุประสงค์การเรียนรู้ประจำบท (Learning Objectives):

  1. เข้าใจเหตุผลและความจำเป็นทางวิศวกรรมในการใช้ ระบบพิกัดทรงกระบอก (Cylindrical Coordinates) แทนระบบพิกัดฉากในปัญหาที่มีความสมมาตรแบบทรงกระบอก (เช่น สายโคแอกเชียล, ขดลวดโซเลนอยด์, เสาล่อฟ้า)
  2. ระบุนิยาม ขอบเขต และความหมายเชิงเรขาคณิตของพิกัดทั้ง 3 ตัว ได้แก่ ρ (Rho), ϕ (Phi), และ z (Z)
  3. เข้าใจคุณลักษณะเฉพาะและทิศทางของเวกเตอร์หนึ่งหน่วย aρ, aϕ, az โดยตระหนักว่า aρ และ aϕ เปลี่ยนทิศทางตามมุม ϕ
  4. คำนวณและประยุกต์ใช้ส่วนย่อยเชิงอนุพันธ์ความยาว dl, พื้นที่ผิว ds, และปริมาตร dv = ρ dρ dϕ dz ในการอินทิเกรต
  5. แปลงจุดพิกัดและแปลงสนามเวกเตอร์ระหว่างพิกัดฉากและพิกัดทรงกระบอกได้อย่างคล่องแคล่วทั้งสองทิศทางด้วยเมทริกซ์การแปลงและตารางผลคูณจุด Table 1.1

1. ที่มาและความสำคัญทางวิศวกรรม (Engineering Motivation)

ในทางคณิตศาสตร์ เราสามารถใช้ระบบพิกัดฉาก (x, y, z) แก้ปัญหาแม่เหล็กไฟฟ้าได้ทุกโจทย์ แต่ในทางปฏิบัติทางวิศวกรรม ปัญหาจริงจำนวนมากมีรูปทรงความสมมาตรเชิงทรงกระบอก เช่น:

  • สายส่งสัญญาณแกนร่วม (Coaxial Transmission Line): ประกอบด้วยตัวนำแกนในทรงกระบอกและชีลด์ตัวนำชั้นนอก
  • สายส่งไฟฟ้าแรงสูงและสายอากาศแบบเส้นลวด (Cylindrical Wire & Antennas): มีการกระจายประจุตามแนวแกนและแผ่สนามไฟฟ้าออกในแนวรัศมีทรงกระบอก
  • ขดลวดเหนี่ยวนำและโซเลนอยด์ (Solenoids & Inductors): ที่มีกระแสไฟฟ้าไหลวนเป็นวงกลมรอบแกนกระบอก

หากใช้พิกัดฉาก สมการขอบเขตของทรงกระบอกจะเป็น x² + y² = a² ซึ่งทำให้การอินทิเกรตซับซ้อนมาก แต่หากใช้พิกัดทรงกระบอก สมการขอบเขตจะลดรูปเหลือเพียง ρ = a (ค่าคงที่ค่าเดียว) ทำให้การคำนวณง่ายขึ้นอย่างมหาศาล

2. อภิธานศัพท์ คำอ่าน สัญลักษณ์ และขอบเขตตัวแปร (Nomenclature & Range)

ตัวแปร (Variable) คำอ่านไทย / กรีก ความหมายเชิงเรขาคณิต (Geometric Definition) ช่วงขอบเขต (Range) หน่วย (Unit)
ρ โรว์ / Rho ระยะทางในแนวรัศมีที่วัดตั้งฉากจากแกน z ออกมายังจุด P 0 ≤ ρ < ∞ m (เมตร)
ϕ ฟาย / Phi (Azimuth) มุมแอซิมัท วัดทวนเข็มนาฬิกาจากแกน +x บนระนาบ xy ไปยังเส้นรัศมี 0 ≤ ϕ < 2π (0° ถึง 360°) rad หรือ deg (องศา)
z แซด / Z (Height) ระยะความสูงตามแนวแกน z (เหมือนกับแกน z ในพิกัดฉากทุกประการ) -∞ < z < ∞ m (เมตร)
aρ Unit Vector Rho เวกเตอร์หนึ่งหน่วยชี้ในแนวรัศมีพุ่งออกจากแกน z (ตั้งฉากกับผิว ρ = const) ขนาด = 1 ไร้หน่วย
aϕ Unit Vector Phi เวกเตอร์หนึ่งหน่วยชี้ในแนวสัมผัสเส้นรอบวงในทิศทางที่มุม ϕ เพิ่มขึ้น ขนาด = 1 ไร้หน่วย
az Unit Vector Z เวกเตอร์หนึ่งหน่วยชี้ตามแนวแกน +z ขนาด = 1 ไร้หน่วย

3. ผิวตัดกัน 3 ผิวและเวกเตอร์หนึ่งหน่วยฐาน (Surfaces & Unit Vectors)

3.1 ผิวตัดกัน 3 ผิวที่ตั้งฉากซึ่งกันและกัน (Mutually Perpendicular Surfaces)

ตำแหน่งของจุด P(ρ₁, ϕ₁, z₁) ใดๆ เกิดจากการตัดกันของผิว 3 ผิวที่ตั้งฉากกัน (Orthogonal Surfaces) ดังนี้:

  1. ผิวทรงกระบอกกลม (Circular Cylinder): ρ = ρ₁ (รัศมีคงที่)
  2. ผิวระนาบกึ่ง (Half-Plane): ϕ = ϕ₁ (ระนาบที่ยื่นออกจากแกน z ทำมุม ϕ₁)
  3. ผิวระนาบแนวนอน (Horizontal Plane): z = z₁ (ระนาบขนานกับระนาบ xy)

3.2 กฎมือขวาและความสัมพันธ์ของเวกเตอร์หนึ่งหน่วย

เวกเตอร์หนึ่งหน่วยทั้งสามตัว (aρ, aϕ, az) มีความสัมพันธ์ตามกฎมือขวา (Right-Handed System):

aρ × aϕ = az   |   aϕ × az = aρ   |   az × aρ = aϕ
ข้อควรระวังสำคัญ: เวกเตอร์หนึ่งหน่วย aρ และ aϕ เปลี่ยนทิศทางตามจุดพิกัด
ในพิกัดฉาก เวกเตอร์ ax, ay, az จะชี้ในทิศทางเดิมเสมอทั่วทั้งอวกาศ แต่ในพิกัดทรงกระบอก ทิศทางของ aρ และ aϕ ขึ้นอยู่กับมุม ϕ ของจุดนั้นๆ:
• ณ จุดบนแกน +x (ϕ = 0°): aρ = ax และ aϕ = ay
• ณ จุดบนแกน +y (ϕ = 90°): aρ = ay และ aϕ = -ax
ข้อสรุปเชิงปฏิบัติการ: ห้ามนำเวกเตอร์ที่อยู่คนละมุม ϕ มาบวกองค์ประกอบ Aρ + Bρ กันตรงๆ ต้องแปลงเป็นพิกัดฉากก่อนเสมอ
โปรแกรมจำลองทัศนภาพพิกัดทรงกระบอกและการแปลงเวกเตอร์แบบเรียลไทม์

4. ส่วนย่อยเชิงอนุพันธ์ในพิกัดทรงกระบอก (Differential Elements)

เมื่อพิกัด ρ, ϕ, z เปลี่ยนแปลงไปเป็นปริมาณน้อยๆ dρ, dϕ, dz:
• ระยะทางตามแนวรัศมี = dρ
• ระยะทางส่วนโค้งตามแนวเส้นรอบวง = ρ dϕ (รัศมีคูณมุมเรเดียน)
• ระยะทางตามแนวดิ่ง = dz

สูตรส่วนย่อยเชิงอนุพันธ์ในพิกัดทรงกระบอก (Hayt & Buck Section 1.8.3)
1. เวกเตอร์ความยาวส่วนย่อย (Differential Length Vector):
dl = dρ aρ + ρ dϕ aϕ + dz az
|dl| = √[ (dρ)² + (ρ dϕ)² + (dz)² ]

2. เวกเตอร์พื้นที่ผิวส่วนย่อย (Differential Normal Area Vectors):
• ผิวทรงกระบอก (ρ = const): dsρ = (ρ dϕ)(dz) aρ = ρ dϕ dz aρ
• ผิวระนาบรัศมี (ϕ = const): dsϕ = (dρ)(dz) aϕ = dρ dz aϕ
• ผิวระนาบแนวนอน/ฝากระบอก (z = const): dsz = (dρ)(ρ dϕ) az = ρ dρ dϕ az

3. ปริมาตรส่วนย่อย (Differential Volume Element):
dv = (dρ) (ρ dϕ) (dz) = ρ dρ dϕ dz

5. การแปลงพิกัดจุด (Point Transformations)

สมการแปลงจุดระหว่าง Cartesian ↔ Cylindrical
จาก Cylindrical (ρ, ϕ, z) สู่ Cartesian (x, y, z):
x = ρ cos ϕ
y = ρ sin ϕ
z = z
จาก Cartesian (x, y, z) สู่ Cylindrical (ρ, ϕ, z):
ρ = √(x² + y²)
ϕ = arctanyx    (ต้องพิจารณาควอดรันต์)
z = z

หลักการเลือกมุม ϕ ตามควอดรันต์ (Quadrant Rules):

ควอดรันต์ (Quadrant) เงื่อนไขพิกัดฉาก การคำนวณมุม ϕ ตัวอย่าง
ควอดรันต์ที่ 1 x > 0, y > 0 ϕ = arctanyx (2, 2) ⇒ ϕ = 45°
ควอดรันต์ที่ 2 x < 0, y > 0 ϕ = 180° - arctan|y||x| (-2, 2) ⇒ ϕ = 135°
ควอดรันต์ที่ 3 x < 0, y < 0 ϕ = 180° + arctan|y||x| (-2, -2) ⇒ ϕ = 225°
ควอดรันต์ที่ 4 x > 0, y < 0 ϕ = 360° - arctan|y||x| (2, -2) ⇒ ϕ = 315°

7. ตัวอย่างโจทย์และแบบฝึกหัดเสริมทักษะ (Worked Examples & Drill Problems)

เกณฑ์ข้อสอบกลางภาค: การแปลงเวกเตอร์ข้ามระบบพิกัด เชื่อมโยงข้อสอบจริง ข้อ 1.2 (15 คะแนน)

หลักการแปลงเวกเตอร์ระหว่างระบบพิกัดทรงกลม (Spherical) และพิกัดทรงกระบอก (Cylindrical):

ใน ข้อสอบกลางภาค ข้อ 1.2 อาจารย์กำหนดเวกเตอร์ในพิกัดทรงกลม A = Ar ar + Aϕ aϕ ณ จุด P(r = 2.4, θ = 50°, ϕ = 70°) และให้แปลงเป็นพิกัดทรงกระบอก (Cylindrical: Aρ aρ + Aϕ aϕ + Az az):

  1. เขียนสูตรตั้งต้นการแปลงทั่วไป (General Form) ก่อนแทนค่า:
    Aρ = Ar sin θ + Aθ cos θ
    Aϕ = Aϕ   (แกนมุมหมุน ϕ ในพิกัดทรงกระบอกและทรงกลมเป็นแกนเดียวกัน)
    Az = Ar cos θ - Aθ sin θ
  2. คำนวณค่าตัวเลของค์ประกอบทีละขั้นตอน:
    • Ar = 2 sin(50°)2.4 ≈ 0.6384,   Aθ = 0,   Aϕ = sin(70°)2.4 ≈ 0.3915
    • Aρ = 0.6384 sin(50°) ≈ 0.4890
    • Aϕ = 0.3915
    • Az = 0.6384 cos(50°) ≈ 0.4103
  3. สรุปคำตอบสมบูรณ์: A = 0.489 aρ + 0.392 aϕ + 0.410 az (ศึกษาเฉลยฉบับสมบูรณ์ได้ใน บทที่ 3 ส่วนที่ 8)
แบบฝึกหัด D1.5 (Hayt & Buck 9th Edition, หน้า 18) การแปลงจุดและระยะห่างระหว่างสองระบบพิกัด

โจทย์:

(a) จงหาพิกัดฉากของจุด C(ρ = 4.4, ϕ = -115°, z = 2)

(b) จงหาพิกัดทรงกระบอกของจุด D(x = -3.1, y = 2.6, z = -3)

(c) จงหาระยะห่างระหว่างจุด C และจุด D (|RCD|)

แสดงขั้นตอนการคำนวณอย่างละเอียด (Step-by-Step Solution) ▼

(a) หาพิกัดฉากของจุด C(4.4, -115°, 2):

x = ρ cos ϕ = 4.4 cos(-115°) = 4.4 (-0.4226) = -1.860
y = ρ sin ϕ = 4.4 sin(-115°) = 4.4 (-0.9063) = -3.988 ≈ -3.99
z = 2
พิกัดฉากของจุด C คือ C(-1.860, -3.99, 2)

(b) หาพิกัดทรงกระบอกของจุด D(-3.1, 2.6, -3):

ρ = √[ (-3.1)² + (2.6)² ] = √(9.61 + 6.76) = √16.37 = 4.046 ≈ 4.05
เนื่องจาก x = -3.1 < 0 และ y = 2.6 > 0 (ควอดรันต์ที่ 2):
ϕ = 180° - arctan|2.6||-3.1| = 180° - arctan(0.8387) = 180° - 39.99° = 140.01° ≈ 140.0°
z = -3
พิกัดทรงกระบอกของจุด D คือ D(ρ = 4.05, ϕ = 140.0°, z = -3)

(c) หาระยะทางระหว่างจุด C และจุด D (|RCD|):

นำพิกัดฉากของทั้งสองจุดมาคำนวณ:
C(-1.860, -3.988, 2) และ D(-3.1, 2.6, -3)
RCD = [ -3.1 - (-1.860) ] ax + [ 2.6 - (-3.988) ] ay + [ -3 - 2 ] az
RCD = -1.240 ax + 6.588 ay - 5.0 az
|RCD| = √[ (-1.240)² + (6.588)² + (-5.0)² ] = √(1.538 + 43.402 + 25.0) = √69.94 = 8.363 ≈ 8.36 เมตร
แบบฝึกหัด D1.6 (Hayt & Buck 9th Edition, หน้า 18) การแปลงสนามเวกเตอร์ (Vector Field Transformation)

โจทย์:

(a) จงแปลงเวกเตอร์ F = 10 ax - 8 ay + 6 az เป็นพิกัดทรงกระบอก ณ จุด P(10, -8, 6)

(b) จงหาองค์ประกอบในพิกัดฉากของเวกเตอร์ H = 20 aρ - 10 aϕ + 3 az ณ จุด P(x = 5, y = 2, z = -1)

แสดงขั้นตอนการคำนวณอย่างละเอียด (Step-by-Step Solution) ▼

(a) แปลง F = 10 ax - 8 ay + 6 az ณ จุด P(10, -8, 6):

หาค่ามุม ϕ ณ จุด P(10, -8, 6):
ρ = √(10² + (-8)²) = √164 ≈ 12.806
cos ϕ = xρ = 10√164 ≈ 0.7809
sin ϕ = yρ = -8√164 ≈ -0.6247

ใช้เมทริกซ์การแปลง [Arc]:
Fρ = Fx cos ϕ + Fy sin ϕ = (10)(0.7809) + (-8)(-0.6247) = 7.809 + 4.998 = 12.807 ≈ 12.81
Fϕ = -Fx sin ϕ + Fy cos ϕ = -(10)(-0.6247) + (-8)(0.7809) = 6.247 - 6.247 = 0
Fz = 6

ตอบ: F = 12.81 aρ + 6 az

(b) หาองค์ประกอบพิกัดฉากของ H = 20 aρ - 10 aϕ + 3 az ณ จุด P(5, 2, -1):

หาค่ามุม ϕ ณ จุด P(5, 2, -1):
ρ = √(5² + 2²) = √29 ≈ 5.385
cos ϕ = 5√29 ≈ 0.9285 ,    sin ϕ = 2√29 ≈ 0.3714

ใช้เมทริกซ์การแปลง [Acr]:
Hx = Hρ cos ϕ - Hϕ sin ϕ = (20)(0.9285) - (-10)(0.3714) = 18.570 + 3.714 = 22.284 ≈ 22.3
Hy = Hρ sin ϕ + Hϕ cos ϕ = (20)(0.3714) + (-10)(0.9285) = 7.428 - 9.285 = -1.857
Hz = 3

ตอบ: Hx = 22.3 ,   Hy = -1.857 ,   Hz = 3
