บทที่ 4: กฎของคูลอมบ์และแรงระหว่างประจุ

แรงไฟฟ้าสถิตระหว่างจุดประจุในอวกาศว่าง: กฎกำลังสองผกผัน, เวกเตอร์ระยะทาง (R12 = r2 - r1), กฎการซ้อนทับ (Superposition Principle), การคำนวณแรงลัพธ์ในอวกาศ 3 มิติ และการหาสภาวะสมดุลแรง

วัตถุประสงค์การเรียนรู้ประจำบท (Learning Objectives):

  1. เข้าใจรากฐานทางฟิสิกส์ของการค้นพบ กฎของคูลอมบ์ (Coulomb's Law) และความสัมพันธ์ของแรงไฟฟ้าสถิตที่เป็นไปตามกฎกำลังสองผกผัน (Inverse-Square Law)
  2. เขียนและคำนวณสมการแรงคูลอมบ์ในรูปเวกเตอร์ได้อย่างถูกต้องแม่นยำ พร้อมระบุทิศทางของเวกเตอร์ระยะทาง R12 = r2 - r1 จากประจุต้นเหตุไปยังประจุเป้าหมาย
  3. เข้าใจและใช้ค่าคงตัวทางฟิสิกส์: สภาพยอมของอวกาศว่าง ε₀ ≈ 8.854 × 10⁻¹² F/m และค่าคงตัวคูลอมบ์ k = 1/(4πε₀) ≈ 8.988 × 10⁹ N·m²/C²
  4. ประยุกต์ใช้ หลักการซ้อนทับ (Principle of Superposition) ในการรวมแรงทางเวกเตอร์จากกลุ่มจุดประจุหลายตัวในระบบ 2 มิติและ 3 มิติ
  5. วิเคราะห์สภาวะสมดุลทางไฟฟ้าสถิต (Electrostatic Equilibrium) เพื่อหาขนาด ตำแหน่ง และชนิดของประจุที่ทำให้แรงลัพธ์เป็นศูนย์ (Fnet = 0)

1. ประวัติและการค้นพบเชิงทดลอง (Historical Discovery & Physics Origin)

ในปี ค.ศ. 1785 ชาร์ลส์-ออกุสติน เดอ คูลอมบ์ (Charles-Augustin de Coulomb) นักฟิสิกส์และวิศวกรชาวฝรั่งเศส ได้ทำการทดลองวัดแรงผลักและแรงดึงดูดระหว่างลูกทรงกลมตัวนำขนาดเล็กที่มีประจุไฟฟ้า โดยใช้เครื่องมือวัดความละเอียดสูงที่เรียกว่า เครื่องชั่งแบบบิด (Torsion Balance)

ผลการทดลองเชิงประจักษ์สรุปเป็นกฎทางฟิสิกส์ 3 ข้อหลัก:

  • แปรผันตรงกับผลคูณของประจุ: ขนาดของแรงไฟฟ้าสถิตแปรผันตรงกับผลคูณของขนาดประจุทั้งสอง (|F| ∝ |Q₁ Q₂|)
  • แปรผกผันกับกำลังสองของระยะทาง (Inverse-Square Law): ขนาดของแรงแปรผกผันกับกำลังสองของระยะห่างระหว่างจุดศูนย์กลางของประจุ (|F| ∝ 1/R²)
  • แนวแรงตามแนวเส้นเชื่อม (Central Force): ทิศทางของแรงจะกระทำอยู่บนแนวเส้นตรงที่ลากเชื่อมระหว่างจุดประจุทั้งสองเสมอ โดยประจุชนิดเดียวกันจะเกิดแรงผลักออกจากกัน และประจุต่างชนิดกันจะเกิดแรงดึงดูดเข้าหากัน

2. นิยามกฎของคูลอมบ์ในรูปเวกเตอร์และค่าคงตัวทางฟิสิกส์ (Vector Formulation & Constants)

สมการกฎของคูลอมบ์ในรูปเวกเตอร์ (Coulomb's Law Vector Form)
แรงที่ประจุ Q₁ กระทำต่อประจุ Q₂ (Force on Q₂ due to Q₁):
F12 = Q₁ Q₂4πε₀ R₁₂² aR12 = Q₁ Q₂4πε₀ |R₁₂|³ R₁₂    (หน่วย: นิวตัน, N)
เมื่อ:
• r₁ = เวกเตอร์บอกตำแหน่งของประจุต้นเหตุ Q₁ (Source Position)
• r₂ = เวกเตอร์บอกตำแหน่งของประจุที่ถูกกระทำ Q₂ (Target Position)
• R₁₂ = r₂ - r₁ = เวกเตอร์ระยะทางชี้จาก Q₁ ไปยัง Q₂
• |R₁₂| = √[ (x₂ - x₁)² + (y₂ - y₁)² + (z₂ - z₁)² ] = ระยะห่างสเกลาร์
• aR12 = R₁₂|R₁₂| = เวกเตอร์หนึ่งหน่วยชี้จาก Q₁ ไปยัง Q₂

ค่าคงตัวทางฟิสิกส์ที่ต้องจดจำในห้องสอบ (Fundamental Physical Constants):

ค่าคงตัว (Constant) สัญลักษณ์ ค่าตัวเลขแม่นยำ ค่าประมาณที่ใช้ในห้องสอบ หน่วย SI
สภาพยอมของอวกาศว่าง (Permittivity of Free Space) ε₀ 8.854187817 × 10⁻¹² 10⁻⁹36π ≈ 8.854 × 10⁻¹² F/m (ฟารัดต่อเมตร) หรือ C²/(N·m²)
ค่าคงตัวคูลอมบ์ (Coulomb's Constant) k = 14πε₀ 8.987551792 × 10⁹ ≈ 8.988 × 10⁹ ≈ 9.0 × 10⁹ N·m²/C²
ประจุมูลฐานของอิเล็กตรอน (Elementary Charge) e 1.602176634 × 10⁻¹⁹ 1.602 × 10⁻¹⁹ C (คูลอมบ์)

3. กฎข้อที่สามของนิวตันและหลักการซ้อนทับ (Newton's 3rd Law & Superposition)

3.1 กฎกริยา-ปฏิกิริยา (Action-Reaction Pair)

แรงที่ประจุ Q₂ กระทำกลับมายังประจุ Q₁ (F21) จะมีขนาดเท่ากันแต่มีทิศทางตรงกันข้ามกับแรง F12 เสมอ:

F21 = -F12    (เนื่องจาก R21 = r₁ - r₂ = -R12)

3.2 หลักการซ้อนทับสำหรับกลุ่มประจุ N ตัว (Principle of Superposition)

เมื่อมีกลุ่มจุดประจุ Q₁, Q₂, Q₃, ..., QN อยู่ในอวกาศ แรงลัพธ์รวมที่กระทำต่อประจุทดสอบ q ณ ตำแหน่ง r หาได้จาก ผลรวมทางเวกเตอร์ (Vector Sum) ของแรงที่เกิดจากประจุแต่ละตัวแยกกันโดยอิสระ:

สมการแรงลัพธ์แบบการซ้อนทับ (Superposition Net Force)
Fnet = F₁ + F₂ + ... + FN = q4πε₀ ∑i=1N Qi|r - ri|³ (r - ri)
โปรแกรมจำลองแรงคูลอมบ์หลายประจุและสมดุลแรง 3 มิติ (Coulomb Sandbox)

ประจุเป้าหมาย Q₂ ณ จุดกำเนิด
ประจุ Q₃ (Source 2) คูลอมบ์ (C)

4. สภาพสมดุลของประจุและจุดสะเทิน (Electrostatic Equilibrium & Neutral Points)

ในระบบไฟฟ้าสถิต ประจุทดสอบ q จะอยู่ใน สภาวะสมดุลแรง (Equilibrium) เมื่อผลรวมของแรงไฟฟ้าทั้งหมดที่กระทำต่อประจุมีค่าเป็นศูนย์:

Fnet = ∑i=1N Fi = 0    ⇒    Fx,net = 0 ,   Fy,net = 0 ,   Fz,net = 0
หลักคิดในการแก้โจทย์หาประจุสร้างสมดุล (หัวใจของข้อสอบข้อ 2.2):
หากระบบเดิมมีแรงลัพธ์ Fnet,เดิม กระทำบนประจุ Q₂ การจะนำประจุใหม่ Q₄ มาวางเพื่อทำให้ระบบสมดุล (Ftotal = 0) จะต้องทำให้:
F42 = -Fnet,เดิม (แรงจาก Q₄ ต้องมีขนาดเท่ากันแต่ทิศตรงข้ามกับแรงลัพธ์เดิมทุกประการ)

5. ตัวอย่างโจทย์และแบบฝึกหัดเสริมทักษะ (Worked Examples & Drill Problems)

แบบฝึกหัด D2.1 (Hayt & Buck 9th Edition, หน้า 30) แรงระหว่างจุดประจุ 3 มิติ

โจทย์:

จุดประจุ Q₁ = 3 × 10⁻⁴ C ตั้งอยู่ที่ M(1, 2, 3) และประจุ Q₂ = -10⁻⁴ C ตั้งอยู่ที่ N(2, 0, 5) ในสุญญากาศ จงหาเวกเตอร์แรง F₂₁ (แรงที่กระทำต่อประจุ Q₁ จากประจุ Q₂)

แสดงขั้นตอนการคำนวณอย่างละเอียด (Step-by-Step Solution) ▼

ขั้นตอนการคำนวณ:

ขั้นที่ 1: หาเวกเตอร์ระยะทาง R₂₁ (ชี้จาก N สู่ M):
r₁ = 1 ax + 2 ay + 3 az   (จุด M)
r₂ = 2 ax + 0 ay + 5 az   (จุด N)
R₂₁ = r₁ - r₂ = (1 - 2) ax + (2 - 0) ay + (3 - 5) az = -1 ax + 2 ay - 2 az
|R₂₁| = √[ (-1)² + (2)² + (-2)² ] = √(1 + 4 + 4) = √9 = 3 เมตร

ขั้นที่ 2: แทนค่าลงในกฎของคูลอมบ์:
F₂₁ = Q₁ Q₂4πε₀ |R₂₁|³ R₂₁
F₂₁ = (8.988 × 10⁹) × (3 × 10⁻⁴)(-10⁻⁴)3³ (-1 ax + 2 ay - 2 az)
F₂₁ = (8.988 × 10⁹) × -3 × 10⁻⁸27 (-1 ax + 2 ay - 2 az)
F₂₁ = -9.986 × (-1 ax + 2 ay - 2 az) = 9.99 ax - 19.97 ay + 19.97 az นิวตัน (N)
|F₂₁| = √(9.99² + (-19.97)² + 19.97²) = 29.96 ≈ 30.0 นิวตัน

6. เฉลยข้อสอบกลางภาคฉบับจริง: ข้อที่ 2 (20 คะแนนเต็ม)

ข้อสอบข้อ 2.1 (10 คะแนน)

คำถาม: จงหาแรงคูลอมบ์บนประจุ Q₂ ที่เกิดจากประจุ Q₁ และ Q₃ เมื่อ
• Q₂ = 2 C อยู่ที่จุดกำเนิด P₂(0, 0, 0)
• Q₁ = 3√3 C อยู่ที่ตำแหน่ง P₁(5, 0, 0)
• Q₃ = 3 C อยู่ที่ตำแหน่ง P₃(-2.5, 5√32, 0)

แสดงขั้นตอนการคำนวณเวกเตอร์แรงอย่างละเอียด (Full Step-by-Step Solution) ▼
ขั้นที่ 1: คำนวณแรง F₁₂ บนประจุ Q₂ จากประจุ Q₁:
• r₁ = 5 ax ,   r₂ = 0 ax
• R₁₂ = r₂ - r₁ = (0 - 5) ax = -5 ax
• |R₁₂| = 5 เมตร
• F₁₂ = Q₁ Q₂4πε₀ |R₁₂|³ R₁₂ = 14πε₀ [ (3√3)(2)5³ (-5 ax) ] = 14πε₀ [ -6√325 ax ] N

ขั้นที่ 2: คำนวณแรง F₃₂ บนประจุ Q₂ จากประจุ Q₃:
• r₃ = -2.5 ax + 5√32 ay ,   r₂ = 0
• R₃₂ = r₂ - r₃ = 2.5 ax - 5√32 ay
• |R₃₂| = √[ (2.5)² + (5√32)² ] = √[ 6.25 + 18.75 ] = √25 = 5 เมตร
• F₃₂ = Q₃ Q₂4πε₀ |R₃₂|³ R₃₂ = 14πε₀ [ (3)(2)5³ (2.5 ax - 5√32 ay) ]
  F₃₂ = 14πε₀ [ 15125 ax - 15√3125 ay ] = 14πε₀ [ 325 ax - 3√325 ay ] N

ขั้นที่ 3: รวมแรงลัพธ์บน Q₂ ด้วยหลักการซ้อนทับ:
• F₂ = F₁₂ + F₃₂ = 14πε₀ [ (-6√325 + 325) ax - 3√325 ay ]
ตอบ: F₂ = 14πε₀ [ (3 - 6√325) ax - 3√325 ay ] N
(หรือในรูปทศนิยม: F₂ = 14πε₀ [ -0.2957 ax - 0.2078 ay ] N ≈ -2.658 × 10⁹ ax - 1.868 × 10⁹ ay N)
ข้อสอบข้อ 2.2 (10 คะแนน)

คำถาม: จงหาขนาด ชนิด และพิกัดตำแหน่งของประจุ Q₄ ที่ต้องวางเพิ่มเติมในระบบ เพื่อทำให้แรงลัพธ์รวมที่กระทำต่อประจุ Q₂ เป็นศูนย์ (สภาวะสมดุล Ftotal = 0)

แสดงขั้นตอนการคำนวณหาประจุเพื่อสร้างสมดุล (Rubric Solution) ▼
เงื่อนไขสภาวะสมดุลบนประจุ Q₂:
Ftotal = F₂ + F₄₂ = 0    ⇒    F₄₂ = -F₂

แรงที่ต้องการจาก Q₄:
F₄₂ = 14πε₀ [ 6√3 - 325 ax + 3√325 ay ] N

การกำหนดตำแหน่งและขนาดประจุ Q₄:
จากสมการ F₄₂ = Q₄ Q₂4πε₀ |R₄₂|³ R₄₂ โดยที่ Q₂ = 2 C และ r₂ = (0,0,0) จะได้ R₄₂ = -r₄
ดังนั้น เวกเตอร์ตำแหน่งของ Q₄ จะต้องอยู่บนแนวแกนเดียวกับแรงต้าน:
ให้วาง Q₄ ห่างจากจุดกำเนิดเป็นระยะ d เมตร โดยเลือก d = 5 เมตร (เพื่อให้สอดคล้องกับรัศมีของ Q₁ และ Q₃):
r₄ = - 5|F₄₂| F₄₂
ขนาดแรง |F₄₂| = 14πε₀ √[ (0.2957)² + (0.2078)² ] = 14πε₀ (0.3614) N

เมื่อแทนค่า d = 5 m และ Q₂ = 2 C จะได้:
2 Q₄5² = 0.3614    ⇒    Q₄ = 0.3614 × 252 = 4.518 C (เป็นประจุบวก)
