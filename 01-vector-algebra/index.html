บทที่ 1: พีชคณิตเวกเตอร์และระบบพิกัดฉาก

รากฐานคณิตศาสตร์เวกเตอร์สำหรับวิศวกรรมไฟฟ้า: ปริมาณสเกลาร์-เวกเตอร์, สนามเวกเตอร์, เวกเตอร์บอกตำแหน่งและระยะทาง, ผลคูณจุด (Dot Product), ผลคูณไขว้ (Cross Product), เวกเตอร์ส่วนย่อยเชิงอนุพันธ์ (dl, ds, dv) พร้อมโจทย์ฝึกทักษะระดับ Textbook

วัตถุประสงค์การเรียนรู้ประจำบท (Learning Objectives):

  1. เข้าใจความแตกต่างเชิงกายภาพระหว่าง ปริมาณสเกลาร์ (Scalar), ปริมาณเวกเตอร์ (Vector) และ สนามเวกเตอร์ (Vector Field)
  2. สามารถสร้างและหาขนาดของ เวกเตอร์บอกตำแหน่ง (Position Vector, r) และ เวกเตอร์ระยะทาง (Distance Vector, R) ระหว่างจุดสองจุดได้อย่างถูกต้องแม่นยำ
  3. เข้าใจและประยุกต์ใช้ ผลคูณจุด (Dot Product) เพื่อหามุมระหว่างเวกเตอร์, การตั้งฉาก และการหาองค์ประกอบภาพฉาย (Projections)
  4. เข้าใจและคำนวณ ผลคูณไขว้ (Cross Product) ในรูปดีเทอร์มิแนนต์, การหาพื้นที่ผิว และการสร้างเวกเตอร์หนึ่งหน่วยตั้งฉากกับระนาบ
  5. จำแนกและคำนวณส่วนย่อยเชิงอนุพันธ์ความยาว dl, พื้นที่ ds, และปริมาตร dv ในระบบพิกัดฉากสำหรับการอินทิเกรตประจุไฟฟ้า

1. อภิธานศัพท์ สัญลักษณ์ และหน่วยมาตรฐานสากล (Nomenclature & Standards)

ในวิชาแม่เหล็กไฟฟ้า ปริมาณทางกายภาพเกือบทั้งหมดแสดงอยู่ในรูปเวกเตอร์ เพื่อป้องกันความสับสน ตารางข้างล่างนี้สรุปสัญลักษณ์ คำอ่าน และหน่วยมาตรฐาน SI ที่ใช้ตลอดหลักสูตร:

สัญลักษณ์ (Symbol) คำอ่านภาษาไทย / อังกฤษ ความหมายทางวิศวกรรม (Physical Meaning) หน่วย SI (SI Unit)
A หรือ r เวกเตอร์ (Vector) ปริมาณที่มีทั้งขนาด (Magnitude) และทิศทาง (Direction) ตามแต่ละปริมาณ
|A| หรือ A ขนาดของเวกเตอร์ (Magnitude / Length) ความยาวหรือขนาดสเกลาร์ของเวกเตอร์ (เป็นค่าบวกเสมอ ≥ 0) ตามแต่ละปริมาณ
ax, ay, az ยูนิตเวกเตอร์ / Unit Vectors เวกเตอร์หนึ่งหน่วยที่ชี้ตามแนวแกน +x, +y, +z (มีขนาดเท่ากับ 1 เสมอ) ไร้หน่วย (Dimensionless)
rP Position Vector เวกเตอร์บอกตำแหน่งที่ลากจากจุดกำเนิด Origin (0,0,0) ไปยังจุด P m (เมตร)
R12 = r2 - r1 Distance Vector เวกเตอร์ระยะทางที่ลากจากจุดต้นกำเนิดประจุ (1) ไปยังจุดสังเกต (2) m (เมตร)
A • B ผลคูณจุด / Dot (Scalar) Product ผลคูณเชิงสเกลาร์ของเวกเตอร์สองตัว ให้ผลลัพธ์เป็นตัวเลข (สเกลาร์) ผลคูณของหน่วย A และ B
A × B ผลคูณไขว้ / Cross (Vector) Product ผลคูณเชิงเวกเตอร์ ให้ผลลัพธ์เป็นเวกเตอร์ที่ตั้งฉากกับระนาบของทั้งสอง ผลคูณของหน่วย A และ B
dl , ds , dv Differential Elements ส่วนย่อยเชิงอนุพันธ์ของเส้นความยาว, พื้นที่ผิว และปริมาตร m , m² , m³

2. นิยามสเกลาร์ เวกเตอร์ และสนามเวกเตอร์ (Scalars, Vectors & Vector Fields)

2.1 สเกลาร์และเวกเตอร์ (Scalars vs Vectors)

• ปริมาณสเกลาร์ (Scalar): คือปริมาณที่บ่งบอกค่าได้อย่างสมบูรณ์ด้วย "ขนาด" (Magnitude) เพียงตัวเลขเดียว เช่น มวล (Mass), อุณหภูมิ (T), ศักย์ไฟฟ้า (V หน่วยโวลต์), ความหนาแน่นประจุ (ρ) และเวลา (t)
• ปริมาณเวกเตอร์ (Vector): คือปริมาณที่จำเป็นต้องระบุทั้ง "ขนาด" และ "ทิศทาง" จึงจะมีความหมายสมบูรณ์ เช่น แรง (F หน่วยนิวตัน), ความเร็ว (v), ความเข้มสนามไฟฟ้า (E หน่วย V/m) และความหนาแน่นฟลักซ์แม่เหล็ก (B หน่วยเทสลา)

2.2 สนามเวกเตอร์ (The Vector Field)

ในทางวิศวกรรมแม่เหล็กไฟฟ้า เรามักไม่ได้ศึกษาเวกเตอร์เพียงตัวเดียว ณ จุดใดจุดหนึ่ง แต่เราศึกษา "สนาม" (Field) ซึ่งหมายถึงฟังก์ชันที่กำหนดค่าเวกเตอร์ให้กับทุกๆ จุดในปริภูมิ 3 มิติ เขียนแทนด้วย:

G(x, y, z) = Gx(x, y, z) ax + Gy(x, y, z) ay + Gz(x, y, z) az

ตัวอย่างเช่น สนามแรงโน้มถ่วงรอบโลก, สนามไฟฟ้า E ที่แผ่ออกจากสายอากาศ หรือสนามแม่เหล็ก H ภายในหม้อแปลงไฟฟ้า

3. ระบบพิกัดฉาก เวกเตอร์บอกตำแหน่ง และเวกเตอร์ระยะทาง

3.1 ระบบพิกัดฉากแบบกฎมือขวา (Right-Handed Cartesian System)

ระบบพิกัดฉากประกอบด้วยแกน 3 แกนที่ตั้งฉากซึ่งกันและกัน (x, y, z) โดยการวางตัวของแกนต้องเป็นไปตาม กฎมือขวา (Right-Hand Rule): เมื่อกวาดนิ้วมือขวาจากแกน +x ไปยังแกน +y นิ้วหัวแม่มือจะต้องชี้ไปตามทิศทางของแกน +z เสมอ (นั่นคือ ax × ay = az)

ตำแหน่งของจุด P(x₁, y₁, z₁) ใดๆ เกิดจากการตัดกันของระนาบ 3 ระนาบที่ตั้งฉากกัน ได้แก่ ระนาบ x = x₁, ระนาบ y = y₁, และระนาบ z = z₁

3.2 เวกเตอร์บอกตำแหน่ง (Position Vector)

เวกเตอร์บอกตำแหน่งของจุด P(x, y, z) คือเวกเตอร์ที่ลากจากจุดกำเนิด Origin O(0, 0, 0) ไปยังจุด P:

rP = x ax + y ay + z az

3.3 เวกเตอร์ระยะทางระหว่างสองจุด (Distance Vector)

หากเรามีจุดสองจุด P(xP, yP, zP) และ Q(xQ, yQ, zQ) เวกเตอร์ระยะทางที่ลากจากจุด P ไปยังจุด Q (แทนด้วย RPQ หรือ rQ - rP) หาได้จาก:

RPQ = (xQ - xP) ax + (yQ - yP) ay + (zQ - zP) az

ขนาดของระยะทาง (Distance |RPQ|):

|RPQ| = √[ (xQ - xP)² + (yQ - yP)² + (zQ - zP)² ]

เวกเตอร์หนึ่งหน่วยในทิศทางจาก P ไป Q:

aPQ = RPQ|RPQ|

4. ผลคูณจุดและการหาองค์ประกอบภาพฉาย (The Dot Product & Projections)

4.1 นิยามเชิงเรขาคณิต (Geometric Definition)

ผลคูณจุด (Dot Product หรือ Scalar Product) ระหว่างเวกเตอร์ A และ B นิยามโดย:

A • B = |A| |B| cos θAB     (โดยที่ 0 ≤ θAB ≤ π)

คุณสมบัติสำคัญ:
1. การสลับที่: A • B = B • A
2. การกระจาย: A • (B + C) = A • B + A • C
3. ผลคูณกับตัวเอง: A • A = |A|² หรือ |A| = √(A • A)
4. การตั้งฉากกัน (Orthogonality): ถ้า A • B = 0 และเวกเตอร์ทั้งสองไม่เป็นศูนย์ แสดงว่า A ตั้งฉากกับ B (θ = 90°)

4.2 นิยามเชิงการคำนวณในพิกัดฉาก (Operational Definition)

เมื่อกระจายผลคูณจุดของยูนิตเวกเตอร์ฐานในพิกัดฉาก:
• ax • ax = ay • ay = az • az = 1
• ax • ay = ay • az = az • ax = 0 (เพราะตั้งฉากกัน)

A • B = Ax Bx + Ay By + Az Bz

4.3 การประยุกต์: การหามุมและองค์ประกอบภาพฉาย (Projections)

1) การหามุมระหว่างเวกเตอร์สองตัว:

cos θAB = A • B|A| |B| = Ax Bx + Ay By + Az Bz√[Ax² + Ay² + Az²] √[Bx² + By² + Bz²]

2) องค์ประกอบสเกลาร์ของ B ในทิศทางของเวกเตอร์หนึ่งหน่วย a (Scalar Component):

Ba = B • a = |B| cos θ

3) องค์ประกอบเวกเตอร์ของ B ในทิศทางของ a (Vector Component):

Ba(vec) = (B • a) a

5. ผลคูณไขว้และการหาพื้นที่ (The Cross Product & Area)

5.1 นิยามเชิงเรขาคณิต (Geometric Definition)

ผลคูณไขว้ (Cross Product หรือ Vector Product) ระหว่าง A และ B คือเวกเตอร์ที่นิยามโดย:

A × B = aN |A| |B| sin θAB

โดยที่ aN คือเวกเตอร์หนึ่งหน่วยที่ตั้งฉากกับระนาบที่บรรจุเวกเตอร์ A และ B ทิศทางหาได้จาก กฎสกรูมือขวา (Right-Hand Screw Rule) เมื่อหมุนจาก A ไปหา B

คุณสมบัติสำคัญ:
1. การไม่สลับที่ (Anti-commutative): A × B = - (B × A)
2. การกระจาย: A × (B + C) = A × B + A × C
3. ผลคูณกับตัวเอง: A × A = 0 (เนื่องจาก sin 0° = 0)

5.2 รูปแบบดีเทอร์มิแนนต์ในพิกัดฉาก (Determinant Operational Formula)

5.3 การประยุกต์หาพื้นที่และเวกเตอร์ตั้งฉากระนาบ

• พื้นที่สี่เหลี่ยมด้านขนาน (Area of Parallelogram): Area = |A × B|
• พื้นที่สามเหลี่ยมที่มีเวกเตอร์ A และ B เป็นด้านประกอบ: Areatriangle = 12 |A × B|

6. ส่วนย่อยเชิงอนุพันธ์ในระบบพิกัดฉาก (Differential Elements in Cartesian)

เมื่อพิจารณาการเปลี่ยนแปลงระยะทางเล็กๆ ตามแนวแกน x, y, z เป็น dx, dy, dz จะได้ส่วนย่อยสำคัญ 3 รูปแบบ:

1. เวกเตอร์ความยาวส่วนย่อย (Differential Length Vector, dl):
dl = dx ax + dy ay + dz az     (|dl| = √(dx² + dy² + dz²))
2. เวกเตอร์พื้นที่ผิวส่วนย่อย (Differential Normal Area Vector, ds):
• บนระนาบ x = const (เวกเตอร์ตั้งฉากชี้แนว x): dsx = dy dz ax
• บนระนาบ y = const (เวกเตอร์ตั้งฉากชี้แนว y): dsy = dx dz ay
• บนระนาบ z = const (เวกเตอร์ตั้งฉากชี้แนว z): dsz = dx dy az
3. ปริมาตรส่วนย่อย (Differential Volume Element, dv):
dv = dx dy dz

แบบฝึกหัด D1.1 (Hayt & Buck 9th Edition, หน้า 7) เวกเตอร์ระยะทางและยูนิตเวกเตอร์

โจทย์: กำหนดจุด M(-1, 2, 1), N(3, -3, 0), และ P(-2, -3, -4) จงหา:

(a) เวกเตอร์ RMN  |  (b) เวกเตอร์ RMN + RMP  |  (c) ขนาดของเวกเตอร์ |rM|  |  (d) เวกเตอร์หนึ่งหน่วย aMP  |  (e) ขนาดของเวกเตอร์ |2rP - 3rN|

แสดงขั้นตอนการคำนวณอย่างละเอียด (Step-by-Step Solution) ▼

(a) หา RMN = rN - rM:

RMN = [ 3 - (-1) ] ax + [ -3 - 2 ] ay + [ 0 - 1 ] az = 4 ax - 5 ay - az

(b) หา RMP และผลบวก RMN + RMP:

RMP = [ -2 - (-1) ] ax + [ -3 - 2 ] ay + [ -4 - 1 ] az = - ax - 5 ay - 5 az
RMN + RMP = (4 - 1) ax + (-5 - 5) ay + (-1 - 5) az = 3 ax - 10 ay - 6 az

(c) หาขนาด |rM|:

rM = - ax + 2 ay + az
|rM| = √[ (-1)² + 2² + 1² ] = √(1 + 4 + 1) = √6 ≈ 2.45

(d) หาเวกเตอร์หนึ่งหน่วย aMP:

|RMP| = √[ (-1)² + (-5)² + (-5)² ] = √(1 + 25 + 25) = √51 ≈ 7.141
aMP = RMP|RMP| = - ax - 5 ay - 5 az7.141 = -0.140 ax - 0.700 ay - 0.700 az

(e) หาขนาด |2 rP - 3 rN|:

2 rP = 2(-2 ax - 3 ay - 4 az) = -4 ax - 6 ay - 8 az
3 rN = 3(3 ax - 3 ay + 0 az) = 9 ax - 9 ay + 0 az
2 rP - 3 rN = (-4 - 9) ax + (-6 - (-9)) ay + (-8 - 0) az = -13 ax + 3 ay - 8 az
|2 rP - 3 rN| = √[ (-13)² + 3² + (-8)² ] = √(169 + 9 + 64) = √242 ≈ 15.56

(a) เวกเตอร์ RAB × RAC  |  (b) มุมที่จุดยอด A (θBAC)  |  (c) พื้นที่ของรูปสามเหลี่ยม ABC  |  (d) เวกเตอร์หนึ่งหน่วยที่ตั้งฉากกับระนาบรูปสามเหลี่ยม aN

แสดงขั้นตอนการคำนวณอย่างละเอียด (Step-by-Step Solution) ▼
